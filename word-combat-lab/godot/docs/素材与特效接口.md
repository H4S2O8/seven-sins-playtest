# 素材与特效接口说明

这份文档写给之后做美术、音效、特效的人（或 AI）。

**原则：动画和移动逻辑全部在代码里，素材只是文件。** 把文件按约定的名字放进 `res://assets/`（即 `godot/assets/`），游戏启动时会自动换上；没放的地方继续用代码画的占位。换素材不用改任何代码，最多改几个 JSON 里的数字。

```
godot/assets/
  minions/      随从身体与配件（glTF / .tscn），路径写在 data/appearance.json
  fx/           战斗特效场景（.tscn），名字见 data/fx.json
  sfx/          音效（.ogg / .wav / .mp3）
  pet/          桌宠“小词”的图片
  icons/        卡面图标（.png）
  table/        牌桌、对手、行动点筹码（glTF / .tscn）
  fonts/        字体（已内置裁剪过的思源黑体）
```

替换完运行 `运行游戏.bat`，或用下面「怎么检查」一节的命令截图核对。

## 1. 随从模型（模块化外观）

文件：`data/appearance.json`，代码：`scripts/view3d/appearance.gd`、`minion_builder.gd`、`proc_parts.gd`。

- **身体** `bodies`：按随从的形象（剑 / 盾 / 咒 / 弓 / 魂）各一个。
  ```json
  "剑": {"asset": "minions/body_sword.glb", "proc": "body_sword", "color": "#b45a52"}
  ```
  `asset` 存在就用它，否则用 `proc` 指定的代码占位。
- **挂点**：身体模型里放空节点，名字叫 `Socket_<挂点>`，配件会挂到对应节点下。挂点有 `head`、`back`、`shoulder_l`、`shoulder_r`、`hand_l`、`hand_r`、`chest`、`waist`、`aura`、`ghost`。模型里没有某个挂点时，配件挂在随从根节点上。
- **配件规则** `rules`：随从装了什么，身上就多出什么。
  ```json
  {"when": {"kw": "首挡"}, "slot": "hand_l", "asset": "minions/shield.glb", "proc": "shield", "color": "#8aa0c8", "priority": 50}
  ```
  `when` 可以写的条件：
  - `kw` 关键词
  - `word` 技能用到的某个词
  - `node` 技能里有某种效果（dmg / heal / watch / time ……）
  - `tag` 技能大类（atk / def / heal / ctl / buff / trap）
  - `template` 用了哪个备选模板

  同一个挂点只留 `priority` 最高的一件。
- **体型** `scale`：生命越高越壮，min / max 限制范围。
- **状态特效** `status_fx`：随从身上有某个状态时显示，如狂振、易伤、护盾、沉默、牵连、升华。

**模型规格**

| 项目 | 要求 |
|---|---|
| 原点 | 脚底中心 |
| 朝向 | 面朝 −Z（Godot 默认的前方） |
| 高度 | 约 0.3 个单位，一个随从大约站在 0.3×0.3 的格子里 |
| 动画 | 可以是静态模型。代码会做前冲、后仰、抖动、倒下、复出、待机呼吸 |

**模型自带动画（可选）**：模型里如果有 `AnimationPlayer`，并且有下面这些名字的片段，就会在对应时刻播放。代码做的位移照常进行，两者叠加。

| 片段名 | 什么时候播 |
|---|---|
| `idle` | 平时，循环 |
| `attack` | 出招前冲时 |
| `hit` | 受击时 |
| `die` | 倒下时 |
| `revive` | 复出时 |

随从对外的动画接口在 `scripts/view3d/minion3d.gd`，和 2D 卡片 `minion_card.gd` 保持一致：

`setup` / `refresh` / `begin_anim` / `end_anim` / `animate_hp` / `float_text` / `flash` / `shake` / `lunge` / `recoil` / `hover` / `set_highlight` / `set_top_view`

想改动画手感，改这些函数即可；战斗界面只调用接口，不关心实现。

## 2. 战斗特效（打击感）

文件：`data/fx.json`，代码：`scripts/fx/fx_player.gd`。战斗界面只会调用 `fx.play("事件名", ctx)`，所有效果都由配置决定。

### 事件

| 事件 | 什么时候 |
|---|---|
| `cast` | 技能起效 |
| `hit` | 造成伤害（小于 `big_hit.min_amount`） |
| `big_hit` | 造成大伤害 |
| `heal` | 治疗 |
| `block` | 首挡格挡 |
| `shield` | 护盾吸收 |
| `trigger` | 监听 / 关键词触发 |
| `chain` | 短时间里连续触发达到 `min` 层 |
| `interrupt` | 打断成功 |
| `kill` | 击倒（分 `mine` 我方得分 / `foe` 对手得分两种） |

### 每个事件可配置的字段

| 字段 | 含义 |
|---|---|
| `sound` | 音效名（见第 3 节） |
| `hitstop` | 顿帧秒数（时间几乎停住一瞬） |
| `shake` | `[幅度, 秒]` 镜头震动 |
| `shake_per_amount` / `amount_cap` | 伤害每多 1 点额外加多少震动，最多按多少点算 |
| `shake_per_n` | 连锁每多一层加多少震动 |
| `big_text` / `big_size` / `size_per_n` / `color` | 屏幕中间弹出的大字、字号、连锁每层加字号、颜色 |
| `fly` / `fly_text` | 是否让分数飞向比分牌、飞的文字 |
| `asset` / `lifetime` | 特效场景（相对 `res://assets/`）和存活秒数 |
| `pet` / `pet_mood` / `pet_dur` | 桌宠随机说的一句话、表情（talk / excited / sad）、显示秒数 |
| `variants` | 按 `ctx.who`（`mine` / `foe`）覆盖以上字段 |
| `min_amount` | 仅 `big_hit`：多大的伤害算大伤害 |
| `min` / `window` | 仅 `chain`：几层起算连锁、相隔几秒以内算连续 |

文字模板里可以用 `{score}`、`{amount}`、`{n}`、`{name}`、`{skill}`。

### 特效场景的约定（`res://assets/fx/*.tscn`）

- **根节点是 `Node3D`**：放到牌桌上那个随从的位置，`ctx.world` 是随从身体中部的世界坐标。适合粒子、光柱等 3D 特效。
- **根节点是 `Control` 或 `Node2D`**：放到屏幕上那个随从的位置，`ctx.screen` 是屏幕坐标。适合 2D 闪光、贴图动画。
- 根节点如果有 `func play(ctx: Dictionary)`，生成后会被调用。可以根据 `ctx.amount`、`ctx.who` 决定大小和颜色。
- `lifetime` 秒后自动删除，场景自己不用管清理。
- `ctx` 里可能有这些字段：
  - `uid` 随从编号
  - `who` 是 `mine` 或 `foe`
  - `amount` 数值
  - `score` 得分
  - `n` 连锁层数
  - `name` 随从名
  - `skill` 技能名
  - `screen` 屏幕坐标
  - `world` 世界坐标

## 3. 音效

代码：`scripts/ui/sfx.gd`。放 `res://assets/sfx/<名字>.ogg`（也可以是 `.wav` / `.mp3`）就会替换代码合成的音。

现有的名字：

| 名字 | 用途 |
|---|---|
| `click` | 点击 |
| `pick` | 选词袋 |
| `declare` | 宣告 |
| `cast` | 技能起效 |
| `hit` | 受击 |
| `heal` | 治疗 |
| `block` | 格挡 |
| `magic` | 触发、连锁 |
| `interrupt` | 打断 |
| `down` | 倒下 |
| `win` | 胜利 |
| `lose` | 失败 |

新增名字只要在 `fx.json` 的 `sound` 里写上，并放对应文件即可。

## 4. 桌宠“小词”

代码：`scripts/ui/pet.gd`。

- **图片**：`res://assets/pet/pet.png` 是基础图，建议 256×256、透明背景、角色居中、脚底贴近下边。还可以按心情放 `pet_normal.png`、`pet_talk.png`（说话时）、`pet_excited.png`（大招、击倒）、`pet_sad.png`（被击倒、对手要打你）。缺哪张就用 `pet.png`。
- **动作**：上下浮动、说话时晃动、开心时蹦跳、跟着新手引导跳到高亮目标旁边，都在代码里，图片只需要静态的。
- **台词放在哪**：
  - 新手引导：`data/tutorial.json`（见第 7 节）
  - 击倒：`data/fx.json` 的 `kill.variants.*.pet`
  - 拼技能的强度感叹：`scripts/game/appraise.gd` 的 `pet_line`
  - 出招前的感叹、对手宣告提醒：`scripts/ui/battle_screen.gd` 的 `_pet_action_line`、`_pet_foe_facts`
- **对外接口**：
  - `Pet.chat(文字, 心情, 秒数)`：随时说一句。
  - `tutorial_show` / `tutorial_end`：新手引导专用。

## 5. 卡面图标

代码：`scripts/ui/icon.gd`。形象字（剑 / 盾 / 咒 / 弓 / 魂）和备选模板的标识，会先映射成图标种类，种类有：

`sword` `shield` `spell` `bow` `wisp` `slash` `burst` `cross` `leaf` `mirror` `swap` `clock` `drop` `split` `swirl` `stack` `arrow` `coin` `ghost` `star`

放 `res://assets/icons/<种类>.png` 就会用图片代替代码画的图形。建议做成白色或浅色的单色图标，代码会按场合染色。

## 6. 牌桌

代码：`scripts/view3d/table3d.gd`。

| 素材文件 | 替换什么 | 规格 |
|---|---|---|
| `res://assets/table/table.glb`（或 `.tscn` / `.gltf`） | 整张桌子 | 桌面高度 y=0，桌面范围约 2.4×1.5，中心在原点 |
| `res://assets/table/opponent.glb` | 坐在对面的对手 | 放在 z=−0.85 处，面朝 +Z |
| `res://assets/table/chip_mine.glb`、`chip_foe.glb` | 行动点筹码 | 一枚约直径 0.1、厚 0.014，代码负责堆叠和飞入飞出 |

- **两种视角**：参数在 `VIEWS`（位置、角度、视角宽度、随从间距）。
  - `seat`：坐在桌前，结算时用。
  - `top`：俯视 5 对 5，宣告时用。
- **意图箭头**：`set_intents`，显示谁在第几秒打谁、打多少。颜色和粗细在 `_arc` 里改。
- **随从铭牌**：名字、血条、状态是 2D 的，任何距离都清晰。样式在 `minion3d.gd` 的 `_make_plate`。

## 7. 新手引导

文件：`data/tutorial.json`。每一步是：

```json
{"id": "b_hand", "title": "第一次出招", "text": "点一下你的【{skill}】。",
 "target": "b:hand", "wait": "select_skill", "pos": "top", "hide": false, "button": "下一步"}
```

| 字段 | 含义 |
|---|---|
| `target` | 要高亮的界面元素（界面代码里用 `Tut.tag(控件, "名字")` 登记） |
| `wait` | `next` 表示点“下一步”才继续；也可以是玩家要做的事件名，或几个事件名组成的数组 |
| `text` | 显示的文字；`{变量}` 会被替换成实际值，如 `{skill}`、`{ap}`、`{foe_t}`、`{cost}` |
| `pos` | 没有高亮目标时小词站的位置：`center` / `top` / `bottom` |
| `hide` | 这一步只等待、不说话 |
| `button` | “下一步”按钮上的字 |

改文案只改这个文件。改完一定要跑一次引导自动测试，见下一节。

## 8. 字体

`assets/fonts/NotoSansSC-subset.ttf` 是按游戏里实际用到的字裁剪出来的思源黑体，网页版也能显示中文。新增文案出现了缺字（显示成方块）时，在 `godot/` 目录下运行：

```bash
python tools/subset_font.py
```
