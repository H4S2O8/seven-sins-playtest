# 反制审计报告（首轮）

## 范围与结论

依据 `README.md`、`词库.tsv` 当前可见内容审计。目录中**没有 `strong-report.md`**；`strong-last.txt` 只记载曾有报告及其概述，没有组合详情，因此无法审计其前五名，不能用猜测代替。以下审计 A–D，并把“强组合能赢”与“有实战可得反制”分开判断。

README 的八词袋抽取比例是待验证假设，不是最终平衡概率。词库没有各词独立抽取权重、调度/保留细则、公开两袋后实际拿牌概率模型，且无法从文件计算“取得指定反制并组成完整技能”的最终概率。报告只给相对稀缺度，不把假设概率冒充实测结果。

另有三个决定性规则缺口：

1. 构筑数字如何换算 AP、每个词/效果的 AP 费率、响应技能是否也要当轮支付，都没定义。下文的 AP 数字是按每点投入数值等额花费、非数值词实例零额外 AP 的**最低估算**；持续时间另按 README 计入数字/AP。若正式费率不同，合法性与时序都需重算。
2. “减少”只说从后接可变数值减去投入值；没有定义“减少生命”是可编效果、是否归类为伤害、是否触发 039/040/042、能否使当前生命低于零或倒下。
3. “同时”明确把同刻次序留给战斗公约；首轮 t=0 的双方即时节点、触发监听器、零时长效果谁先执行未知。若任一边能在 t=0 先杀死/打断另一边，以下同刻结论会变；若承诺锁定行动后双方行动不可取消，则行动者即使先倒也可能照常结算。README 未选定其中任何一种。

## 共用判定

“实际失去生命”包含伤害及其他直接失去生命来源（042）；“受到伤害”与“造成伤害”只由实际伤害触发（039、040）。因此，明确的直接失去生命效果会绕开只对伤害生效的减伤、首挡、不屈，并仍可能触发 C 的 042 监听器。若直接“减少生命”是合法、可直接对敌方使用且金额可任意投入的行动，它是通用防御旁路；若能快速铺全体或重复发动，就构成“先清除全部生命防御”的必胜路线。**这属于体系失败，不算健康反制。**但因缺少“减少生命”的目标语法、数值边界、AP 费率、响应可打断规则，本报告不能断言它在当前版本已是合法且必胜的具体技能；它是必须优先封闭的致命歧义。

## A：本方全体受伤转治疗（20 秒）

**进攻基线**：08/027/014/016/062/10（转为/全部/友方/随从/持续/施加），20 秒；若按单张卡每技能需实际动作和对象补全，README 尚无形式文法可唯一解析。装备到一名施法者，最低至少 6 个词实例；若效果只对“施加”目标生效，仍不清楚如何把伤害事件类型指派给全队，故这是按 README 明确假设 #2 的语义强度评估，非已定稿解析。持续数字20，最低估算20 AP，首轮行动点10无法单独支付；第2轮累计30可支付，或更低时长/预留 AP。必须在伤害之前完成施加。

**反制 A1（延命/拒绝馈赠）**：005 减伤，对关键队员预装足量固定减伤；每个防护角色一个词实例（共1–5个），预算20给每名目标时按 README 暂例减10/伤害段；数字20各自计 AP。先手方需在 A 窗口施加前公开减伤，后手看到施加后若对方同刻发动，能否赶在伤害前由 t=0 规则决定。减到零的伤害不应成为治疗（转改写的是“即将结算效果”，但先后次序未定义）。词袋难度：减伤是基础常见词；足额数值可能贵。结果：能压低转换治疗、令进攻方空转；**通常不赢，只延命/迫使换打法**。若伤害源可堆高数值且减伤只有有限数值则非持久解。

**反制 A2（直接生命减少）**：候选词007+004+015+016（减少生命敌方随从），可只需4实例；数字按目标生命投入，估计每失去1点花1 AP。先后手若可 t=0 立即施加，先手可能越过“伤害转治疗”而直接杀人，后手能否响应/是否仍结算未知。词项频率：007、004、015、016均基础，拼词获取容易。战前预装不一定需要，若宣告行动 AP 足够即可。**此不是合格健康反制**：若规则确认它直接扣当前生命且无上限/AP限制，它会通吃防御并破坏体系；须先定义语义再给平衡结论。

## B：每次实际恢复生命，向全体敌方造成双倍实际治疗量

**进攻基线**：038/041/059/014/016/003/033/015/027/002/074/075（当恢复生命每次，本方随从治疗；对全部敌方随从造成双倍该次实际治疗的伤害）。示意约12个实例；施法者与治疗来源如何绑定、双倍引用哪一个数值需按词法审定。投入治疗数字H、持续轮次/20秒窗口按技能具体构筑；每次触发造成2H范围伤害，/AP 是否按实际发动次数扣费未知。触发所监听的是实际恢复，满血无效治疗不会触发。行动锁定后先手宣告恢复/触发器，后手才响应。若预装监听器跨回合生效，反制窗口很窄。

**反制 B1（常见，条件性胜负）**：把己方血量维持满值，使敌方治疗全部溢出，按041不发生“实际恢复生命”，从源头不给 B 触发；所需词实例0（站位/已满生命），不花 AP。战前准备：让所有可能被该效果治疗的单位满血；若施法者可自疗，预先造成/保留可控伤口给它实际治疗，则反而会触发，故不应误伤。词袋难度：无特定词，但需血量管理。先后手：若生命值在公开行动前可知且己方已满，先后手相同；后手若本轮先被打伤则失效。结果：在双方生命满且不被压伤时，**确实使本轮该发动无效，但只是防御/延命**；不杀施法者、不夺胜。溢出治疗的存在有036，但无需它。

**反制 B2（伤害打断施法者）**：002/001/014/016/026（造成伤害本方指定目标敌方施法者）约5词，伤害数值D按投入/D AP估；若在治疗前造成致命伤害，能否取消已锁定的监听/动作取决于未定义的死亡与行动取消规则。先手锁 B 后对手响应：后手同刻打死来源，t=0 顺序决定是否挡下治疗；若行动支付后不可取消，则可能仍执行。需要战前预装或快速行动未知。词袋难度：基础词多，易获取；但有效打断需要足够伤害。结果：只有规则允许打断时是真反制，否则仅造成伤害，无法阻止范围触发；可赢的具体性不足。

**反制 B3（直接减少生命）**：同 A2；可击杀低血目标绕过伤害防御，但来源与连锁可能仍触发042。因核心语义未知，不算可接受反制。若对敌方使用减少其生命，触发的失去生命事件不是治疗事件，B 本身不因此反击（但 C 可能反击）。

## C：敌方随从每次实际失去生命时复制该伤害

**进攻基线**：038/015/016/059/042/012/002/074（当敌方随从每次失去生命，复制该伤害）。至少8词实例；但“失去生命”可以来自非伤害，词012要求复制效果实例，词042事件本身未必携带可复制的伤害节点——这里存在关键类型不匹配：若目标事件是非伤害失去生命，“该伤害”不存在。对伤害事件则按实际失血复制。给每次基础伤害D；每个实际失血可向另一个目标复制D，复制后的失血可能触发其他监听器，循环深度依赖 README 因果链规则。每次复制的 AP 成本及跨触发预算均未定。

**反制 C1（常见减伤，抑制事件）**：005 预装于全队，配置足额减伤令命中实际失血为0，则042不发生，C 无复制。每队员1个减伤实例；投资每人20的 README 暂例可抵每段10。AP：每个投资数额合计，首轮可能支付不起全队配置；须战前构筑预装（且词卡不能免费跨卡复制）。先后手：需在 C 的首击前已有减伤；看到行动后临时安装是否来得及由响应时序决定。难度：基础词常见，但多张卡与数值预算成本高。结果：能阻止低伤攻击触发复制，**只延命**；对超过减伤值的强伤仍触发，不是稳定胜利线。

**反制 C2（回血不是撤销事件）**：003恢复只能补生命，不能撤销“实际失去生命”事件或已创建副本，不构成事件层反制。036溢出也不帮助阻止伤害。回复超过实际损失会被上限截断，但复制链早已启动。

**反制 C3（反杀来源）**：002/001/014/016/026 对复制器施加足够伤害，5实例左右，预算D/AP；若能在其首个监听事件前击杀则须规则允许打断。若 C 已经预装，击杀持有者不会自动删除已存在的复制效果；“保留已装词”复出还会恢复威胁。先手后手同刻歧义显著。词袋难度较低（基础伤害组件），结论取决于打断规则，当前不能认定真反制。

**判断**：C 是四项中最难找到稳定、实战可得且能赢的防线。没有通用“取消已经发生的失去生命触发”词。重复恢复能延命但非胜利；低值伤害可被减伤压制，叠加高伤/多目标后又失效。若直接减少生命会触发042，却不触发039/040，C 可以由自身事件复制的语义断裂进一步制造规则漏洞。

## D：首挡、不屈、三种状态免疫堆叠

**堆叠构筑**：每张卡最多一个该实例，且实例不能免费跨角色复制。全队五张可放置首挡096与不屈097各一，共10实例；三种免疫093–095若也要全队覆盖，另15实例，总计25个关键词实例。所有词的具体装备位限制、是否可在每人技能内并列未定义；按一个词一个技能且每张卡可多技能理解。它们是防护/免疫关键词，不必然消耗AP，但规则未明确。频率是首挡/不屈进阶，三免疫奇术，实际词袋稀缺度依次较高；README 的模型只给“进阶24%、奇术4%”，不能换算指定词卡的最终取得率。

**攻击反制 D1（常见伤害包拆分）**：两次独立正伤害包可先消耗首挡、再让第二包造成实际伤害；每次约5实例（001/002/015/016/026），数字各为d1,d2，合计AP估 d1+d2。对不屈，令一包使目标降至1，再一包伤害击倒（不屈只在“首次应被伤害打倒”时改为1，之后可伤害打倒）；首挡若尚未消耗须先另有一个伤害包。故击穿首挡+不屈对一个目标最少3个先后伤害包（首挡包、打到1包、致死包），额外约15个词实例，数值预算不低。首挡包可以是无害1点伤害，但对面回击/被动会另触发。时间轴按先后错开正时间即可避开同刻顺序，但总计20秒内，D 防护可能在 t=0 自动生效。攻击词基础常见，词实例和AP成本较高。结果：能耗掉每场一次性防护并击倒单个目标；对五名全队目标需重复铺包，且死亡下一轮复出，**是局部真反制，不保证赢**。

**攻击反制 D2（状态免疫）**：免疫093/094/095只分别阻止狂振/牵连/升华附着；不阻止普通伤害、治疗或直接生命变化。使用伤害路线不需要解免疫，故常见伤害组合自然绕过免疫。若攻击依赖状态则不能以“移除状态”对付免疫，因为免疫发生在施加前；但普通攻击仍可赢。关键词词袋获取：伤害相关基础词常见，且只需无状态技能；如果攻击方已把数值过多投资状态增益，则需要换构筑/词牌调整（每轮两次调整），不算即时反制。

**反制 D3（直接减少生命）**：若合法则绕过首挡/不屈，因为这两个只处理“伤害”；还能不受三种状态免疫影响。基础词003? 使用007+004等。其通吃性使 D 的防护投资失去意义，也是体系失败警报，不记为健康反制。

## t=0 同刻敏感性

结论敏感且未被 README 解决。A 的即时“转为/施加”与首个伤害若都在0秒：转化先结算则伤害变治疗，伤害先结算则可能先扣血；B 的即时击杀与恢复触发谁先发生会决定触发；C 的即时首击与击杀监听器先后决定复制是否建成；D 的首挡与并发多包谁先拿走“一次”会决定哪一包归零。若状态施加在0秒但持续20秒，到期边界是否含20秒也未明。不能把“后手响应”自动视为能插入一个早于 t=0 的反应；README 只说双方行动沿同一时间轴执行，没有响应动作时间、优先级或打断规则。

最小必要的公约是：每个时间点先处理公开行动建立/目标锁定，再按先手标记决定同刻事件队列，事件内部固定顺序为“减伤/改写 → 实际伤害或治疗 → 生命/倒下检查 → 事件触发 → 复制/接续产生的新实例”；新增实例在队列尾部深度优先或广度优先二选一，统一规定；倒下是否取消已支付行动也需写明。必须说明反应技能可以在同刻队列的哪个窗口插入，不能默认有负时间。

## 结论清单

### 有真反制（至少在限定条件下）

1. A 转伤治疗：常见足额减伤在伤害前预装可把转化的输入压成0，能让组合空转；但通常只延命，且高数值可穿透。
2. B 治疗触发器：目标在行动前全满血时，所有治疗溢出，不产生041事件；本轮确实阻止触发，前提是没有先受伤。
3. C 复制伤害：足额预装减伤令实际失血为0时没有042，低于防护阈值的来源会被关闭；高伤下不成立。
4. D 首挡：用一个低风险伤害包消耗首挡后，后续包不再被首挡归零。
5. D 不屈：先将目标降至1，再用独立正伤害包击倒；与首挡同在时需先耗首挡。
6. D 三免疫：不靠状态的基础伤害攻击不受状态免疫影响，可用常见词进攻。

### 没有可接受反制或信息不足

1. A 对“全部受伤转治疗”的快速大数值持续覆盖：减伤投入被突破后没有通用即时解；直接减少生命若可用则是旁路而非健康反制。
2. B 在目标被预先压伤后，治疗同时成为全体双倍伤害：没有词能取消已发生的实际治疗触发；打断依赖不明的死亡取消规则。
3. C 对全体任何实际失血复制：普通治疗不撤销触发；不够高的减伤不能稳定挡住组合，复制链终止语义不充分。
4. D 五人全队同时拥有首挡+不屈并堆叠状态免疫：攻击方必须为每目标支付多包伤害和时间/AP；没有低成本即时破解，复出还保留这些词。
5. 任何把“减少生命”当作不受限制的直接扣血路线：若合法，可绕过伤害防御并成为通用必胜工具；当前无法判断可行性，因为词义、语法、费用和边界均缺失。
6. strong-report 前五项：材料缺失，无法审计。
7. 一切依赖 t=0 同刻竞速、死亡打断、复制事件顺序的反制：规则未定，不能给确定胜负结论。

## 最小通用修订建议

1. **定义“减少生命”**：建议明确它只能改变宣告数值/治疗量等效果输入，不直接操作当前生命；若设计确实要直接扣生命，应把它命名为独立效果，规定减伤、首挡、不屈是否适用、是否触发伤害/失去生命监听、倒下检查、最低值、每目标上限与AP费率。不要留下“减少生命”可被解释成无视所有防御的免费动作。
2. **统一事件与时序**：给出同刻队列、先手优先、响应窗口、倒下时已锁定行动是否取消、状态持续边界、复制/触发新实例顺序。t=0 必须和其他时间点一样确定。
3. **把触发所需事件类型写清**：复制“该次伤害”只允许从实际伤害事件读取；若监听042也涵盖直接失去生命，非伤害事件不得凭空生成伤害数值。逐项规定实际值是在减伤/转化前还是后读取。
4. **限制通用连锁的预算而非禁组合**：规定每个响应/触发/复制节点的AP支付时点与费用，单次锁定行动可创建的事件预算，超预算如何停止；因果链“自身不反复触发自身”不足以说明多实例互触时的终止与对局长度。
5. **明确词实例及战前预装**：每词在一队可用实例总数、调整时能否换词/重置数字、已公开后是否可变、复出保留技能的具体范围。否则“拿到词袋并发动”的实战概率无法计算。

**总评**：当前材料不足以证明强组合有可获得且能赢的反制。A、B 有常见条件性压制手段；C 缺稳定胜利型反制；D 能被标准伤害逐步耗尽但部署成本高。最大风险不是某张强牌，而是直接减少生命和事件时序未定义：若前者是通用旁路，体系失败；若后者不定，纸面反制无法落实为可执行对局。
