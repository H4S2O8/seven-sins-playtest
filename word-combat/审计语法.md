# 拼词审计语法 v0.2（实验规则，尚未确认为成品规则）

本文件给强组合和反制一个共同的合法性标准。词可以任意组合，但每个词必须有确定的语法位置；不能为某个强组合临时补上省略的「目标」或「持续」。未在这里定义的拼法一律标为**未定**，不算压测成功。

## 装配与宣告

- 一张随从卡可以装一张有限的**有向无环技能图**。结果节点是「造成伤害」「恢复生命」「施加状态」「减伤」「移除状态或限时效果」。连接词形成条件、分流、接续、并列、择一等节点。每个抽到的词实例只占一个节点，不能凭一个词同时建两条独立结果节点；但已经定义的纯对象集合和纯数值引用可以从同一节点接出多条线。例如一次写出 `敌方 随从`，可供同一技能中的“先选择一个敌人，再作用于全部敌人”两条分流引用，且不会凭此复制任何伤害数值。
- 直接效果必须有**动作、对象、范围、数值**。例如 `造成 伤害 / 选择 目标 一个 敌方 随从 / 填入6` 合法；缺少目标表达式则不能宣告。`恢复 生命` 同理。被动关键词不占技能树，按自己牌面执行。
- 对象由 `友方/敌方 + 随从` 限定；`自身`是完整的单体对象。`一个`配合`选择 目标`由行动方在宣告时指定一张活牌；`最前/最后/最高生命/最低生命/随机`可取代`选择 目标 一个`。`全部`覆盖指定阵营的活牌，逐个产生一个结算实例。相邻必须显式引用中心。`限时效果`用于指明要移除或引用的已公开限时效果，不能省略成一次万能驱散。
- **所见即所得**：`全部/每个` 把同一填入数值原样作用于每个合法目标。例如填入 20 点伤害打五人，就是每人受 20 点伤害；`分流`仍只分配原投入总额。通过公开数字预算、行动点、生命分配、减伤、治疗、伤害转化和反杀来审计其平衡，不给范围攻击临时加专属折扣或削弱规则。
- `当 + 事件 + 效果` 建立监听器；不写 `每次` 就在有效期内仅响应第一次。`下一次`、`第一次`也仅一次。写 `每次` 才能在有效期内响应多次。限时监听器须有 `持续 + 1至20`；不写持续则只维持本轮。监听器自身需要指定其观察对象；执行叶子还需要自己的目标表达式，两者可用 `来源/接受者` 等引用相连，不能默认相同。
- `转为`须连接两个完整类型的叶子，产生一个改写器，另须明确被监听的事件与承受改写的对象。改写器自身不产生伤害或治疗。此语法允许「将友方受到的伤害转为治疗」，但需要显式的监听、转换双方和目标词，不能只写三个抽象名词。
- `复制`须引用一个已结算事件及新目标；复制按目标重新走防御、状态和事件链。`移除 限时效果 / 选择 目标 一个 敌方 随从`须再点选该随从维持或附着的一项公开限时效果；被选效果若是全队监听器，则整个监听器结束。`减少 当前生命`按伤害结算。`增加 当前生命`按治疗结算。
- 构筑预算100点包括生命上限、技能各填数值和各个持续时间。测试中的主动发动费是统一 **5点启动费 + 此次执行的完整分支中全部填入的非生命数值**，在宣告时一次支付；未选分支不收费。由引用读出的实际伤害等不是再次填入的数值，不另收费。已经支付并安装的触发器响应时不重复收启动费。`重复`每次执行须重新支付被重复节点的填数值，但同次宣告不重复收整张技能的启动费。5点是待对照3/5/8后的试验值。
- 双方均公开已装技能树、生命与数值；先手宣告目标、分支、时间并支付，后手看见后宣告并支付，随后共同进入20秒时间轴。双方已经锁定的行动不能再改。

## 同时刻与因果链

同一时刻依次：建立限时效果与状态；结算移除；计算替换和减伤；合并同一目标的直接伤害与治疗；结算有限派生链；最后按 `最终生命 = 限制到[0,生命上限](原生命－同刻伤害＋同刻治疗)` 判定倒下与全灭。过量伤害不能在加治疗前先截到0，例如10生命、30伤、1治疗仍倒下，30伤、25治疗剩5。`移除`只能清掉已经建立的效果；若同刻建立又移除，就按此顺序生效。同类同时改写冲突、互相转为和未定义引用，一律标**未定**，下一轮统一修规则后才测试。

一个直接事件开启一个因果链；这条链中同一个装配的词实例最多执行一次。不同直接事件分别开链。因此多段可以分别触发，但复制—触发—复制不能无穷循环。此规则只防无限循环，不保证数值强度合理。

## 编辑器应当显式提供的连接（消除纸面语法歧义）

这不是额外赠送词。界面只负责把已经抽到的词连接到有类型的插槽，并显示完整句子。没有装入相应词，就不能创建该节点或目标。纯目标集合、数值引用可以在同一张技能图内分叉使用；跨两张卡仍必须各有自己的词实例。

- `目标式`：`自身`；或 `选择 目标 一个 阵营 随从`；或 `最前/最后/最高生命/最低生命/随机 阵营 随从`；或 `全部/每个 阵营 随从`；或从当前事件读取 `来源/接受者`。`另一个`需要先有已绑定目标。一个技能树可有多个目标式，但每次使用同一词实例只能放在一处。
- `数值式`：一个由玩家填入并从100点构筑预算扣除的非负整数；或 `该次伤害/该次治疗/实际数值/原始数值/当前生命/失去的生命/已投入数字`等明确引用。`双倍/一半/差值/合计/较高者/较低者`只变换已连接数值；不能自己产生无来源数值。
- `效果叶`：`造成 伤害(目标式,数值式)`、`恢复 生命(目标式,数值式)`、`减少 当前生命(目标式,数值式)`、`增加 当前生命(目标式,数值式)`、`减伤(目标式,数值式,固定或比例,有效期)`、`施加 状态(目标式,有效期)`、`移除 状态/限时效果(目标式,公开实例)`。治疗/生命增加与伤害/生命减少分别进入完全相同的结算管线。主动状态若无 `持续`，只维持本轮；没有填数的主动状态仍占本轮唯一行动，不另收费。
- `触发节点`：`当 事件(观察目标式) [第一次/每次/下一次] [持续] → 效果树`。默认只触发首次，默认有效到本轮结束。当前事件给子树提供 `来源`、`接受者`、`该次伤害`或`该次治疗`；引用不存在时该分支不执行。响应者可在 t=0 建立节点，本刻先安装、再移除、再结算伤害与治疗，所以确实来得及响应同刻尚未结算的伤害。
- `即将受到伤害`在生命改变前给出**待结算事件**，可以由 `转移` 等改道；旧词 `受到伤害` 只在实际失血后发生。两者不是同一时机。`转移(当前待结算事件,新目标式)`保留原伤害/治疗/状态的类型、数值和来源，只替换接受者，原接受者不再承受，不复制数值。新的接受者可以是原事件的 `来源`，但必须仍是该类型效果的合法目标。若新接受者也有转移效果，该事件可继续改道；一条因果链里每个已装词实例最多执行一次，故改道链有限。
- `接续(前效果,后效果)`把前效果实际结算的数值接到后效果的数值插槽；后效果仍须有自己的目标式，不能凭连接词免费选人。`分流(总填数,分支甲,分支乙,间隔)`让玩家公开分配甲乙数值，总和为填数，间隔由编辑器设置且不额外占数字。`并`两棵完整效果树都执行；`择一`在宣告时选一棵完整树；`重复`重新执行一棵树并重新支付其填数。
- `复制(已经结算的效果实例,新目标式)`建立同类型、同实际数值的新效果实例，从头经过防御和触发。若引用的是失血事件但并非伤害事件，就不能当成“该次伤害”复制；必须按所引用的实际事件类型处理。`转为(被观察效果类型,新效果类型,观察目标式,承受目标式,有效期)`将进入结算的效果替换成另一类型，再走新类型管线；两个目标式可通过事件中的 `接受者/来源`连接，若没有明确绑定就是非法句。
- `牵连`有两个目标插槽，第二个必须是同队另一随从；`升华`把实际治疗输入存为下次伤害增量，若该次治疗被改写为升华则不同时回生命；`狂振`伤害倍率暂按 README 的25%测试。倍率、舍入和复出次序要在真实结算器中固定，不能由玩家或审计者逐案选择。

以上只定义通用类型和连接，不写“遇到全体攻击时怎样”的专门条款。每张装配完成的卡应把这些连接以人话渲染；玩家看见的是最终数值和触发条件，不必阅读 AST。

## 词袋待修问题

原纯随机袋计算显示：六个指定基础词的单体攻击，到第8轮只在约2.4%的样本凑齐。这使强组合和反制几乎都不会出现，属于词袋经济失败，不能拿来证明平衡。下一步比较「仍然从词库抽取、但保证开局有完整基本句、后续按语法角色分袋」的模型；这是测试方案，未擅自确认为最终发牌规则。
