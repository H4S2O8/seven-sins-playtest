# 双面交锋：20数字 / 35卡组 可玩流程版

本次完成的是可打开、可组卡、可完成对局的文字原型，不是完整卡池交付。

- 82张可用卡：41主牌、6辅牌、35公共条款，全部解锁。
- 七职业各三套35张试作预设；保存、另存、改名、搜索、过滤、导入导出。
- 22节分步骤教程，包含开局换牌、实际出牌与结果验证。
- 基础电脑仅读取公开视图和自己的手牌，不读取敌方手牌或牌库顺序。
- 数字1—20各用一次，起手5，可换任意张一次，卡组35，同名上限3。
- 局部逻辑测试、21组本地算法对战及浏览器整局测试。它们不代表平衡性或趣味性审查已经完成。
