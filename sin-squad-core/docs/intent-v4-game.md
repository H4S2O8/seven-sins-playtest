# 暗流 v4：单场地、公开意图与实际游戏

本文件与 `src/intent/content.ts` 的 `intent-v4-single-field` 为当前版本。网页首页的「七罪 · 暗流」使用这一引擎；原战役、自由牌桌仍使用其原引擎。复用原有立绘、牌背、物理卡壳、卡框、灯光、房间与毡布素材，没有另造一套美术。

## 一手的流程

1. 亮一条当前场地，发三个3–10数字和九个人物候选。同名候选可重复出现、重复选取；每个人物恰好一个主动技能，可以另有基础能力。
2. 九选三，候选可换一批。人物与数字各自排位；可以点击交换或拖动人物。提交初始技能，双方齐备后公开是否发动、类型和目标；精确身份、原数、模式仍隐藏。
3. 下注之后，前三轮各一次装备机会。跳过免费；付2后必须三选一装到空位，没有替换、退款或弃选。装备结果双方选完才一起公开。
4. 每轮装备后翻一张候选场地，双方选择替换/保留并密封出价0–6。双方出价进入底池，高价者决定，同价保留。替换时旧效果立即失效，始终恰好一条生效。未来候选不提前暴露。
5. 每轮竞拍后双方各提交一次技能计划。第三轮后人物、装备、技能全部锁定。后续只下注；第四轮起双方过牌即摊牌，全押提前摊牌。
6. 固定对位比较最终力量，赢更多位置者获底池，平局平分。不再叠加额外胜利规则。弃牌不揭示身份。下一手筹码延续，先手交替；刷新重放存档恢复状态，包括已付费的装备候选与未公开提交。

## 50字的黑盒分析

每张己方人物的技能指向旁显示一栏分析，每栏不超过50个字符。只显示输入、输出及装备/场地对己方终值的影响，不展示事件队列、触发链、公式推导或中间结算步骤。完整卡面规则仍可点「?」或装备名查看。

例：「例：付4→送友9；装2位+3；场1位+4/2位+2」。收、受削、付表示该位实际输入；送友（包括自身）、削敌表示该位发出的效果。装、场分别是保留同一敌阵与其余配置、移除该因素所得的己方终值差；不是互相独立、可相加的收益。无净变化既可能未触发，也可能被其他收益/代价抵消。复杂局面的紧凑三数按左、中、右排列。

内部复用真实 `battle()` 事件解释器及合法观察层。摊牌前仅从公开构成、已公开装备和已确认指向生成合法敌阵示例，显示「例」而不假装知道对方暗牌；「分析怎么看」解释假设。此示例不是预测胜率、保证输出或完整上下界。摊牌后用揭示双方阵容重新实算，显示「实」。技能本地草稿、装备安装、场地替换与新公开意图都会重算。

AI复用已有状态机，在Worker内只接收其合法观察信息，不接收整张牌桌或牌桌种子。构建按Worker内容哈希命名，避免发布后新旧代码错配。它仍是有限样本的启发式对手，不能视作最佳策略。

## 验证与证据边界

引擎/接入回归覆盖：单场地替换与后续同价保留、重复人物、技能锁定、付费必装、暗牌隔离、存档重放、半筹码全押/短筹码底注、连续手筹码、摊牌分析与实战结果一致、29人物及24装备的短文分析字数。

网页实际验证包括重复选人、交换数字、发动与改向、付费候选刷新恢复、安装聚焦镜、竞拍替换场地、手机375px布局及底部操作区。构建和检查结果记录于PR。

v1/v2/v3的1000桌、200桌及模型实战报告均为历史设计实验，不能当作本版平衡或乐趣证据。本轮完成规则与产品接入，不重复大批量模拟，不声称「已证明质变」。
