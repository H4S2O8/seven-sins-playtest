# v3：过程型场地

> 本文件保留v3及过渡修订历史。当前已接入前端的规则、50字黑盒分析与验收要求见 [v4游戏](intent-v4-game.md)，其约定优先。

## 最新修订：单场地替换与箭头预览

以下修订优先于本文后面的历史叠加描述：场上始终只有一条生效场地。开场一条立即生效；前三轮各翻一张候选，竞拍决定替换当前场地还是保留当前场地。双方出价仍进入底池，高价者立场生效，同价保留当前场地。替换成功时旧场地立即失效，被否决或替下的场地不会自动恢复。三轮之后不再翻牌。

规则引擎和状态机已改为比较“仅旧场地”与“仅新场地”。下方多场地同时处理顺序仅作历史引擎说明，正常牌桌不再产生叠加场地。此前200桌与5桌报告属于叠加版，不能当作本修订的测试结果。

前端待实现：装备卡写明完整效果，技能箭头旁显示当前装备、唯一场地及己方已知配置如何改变输入、路径与输出。简短标签展示最重要的变化，展开查看按真实结算顺序的来源与过程；无目标的强化、抉择和翻面在人物旁用同等层级标记。

预览须区分确定变化与条件变化。例如“实际转出x → 接收2x”，不能把未保证支付成功的5写成必定收到10。依赖敌方隐藏技能、模式或精确数字的结果只展示条件，不访问暗牌。己方可确定的多段组合应合并展示，不能只列装备原文让玩家自己心算。箭头表示选择目标，改道后的落点要另行标明。发动、关闭、指向、装备或场地改变时同步更新；第三轮后锁定。这些是验收要求，尚未实现UI。

本版为纯代码实验，尚未接入旧数字模式前端。v1/v2结果均是历史版本，不可用新结算器重放后当作旧证据。

## 流程与公开信息

开局随机亮出一条效果，立即生效；数字直接以原值入场，没有基础场地。之后选人、配数、排位和提交初始技能，再下注。

前三轮各有一次装备机会。双方完成本轮装备后，只翻出一条新效果，同时各自提交启用/否决立场及密封出价。沿用每人0–6筹码、双方出价进底池的规则；高价立场生效，同价不开启。开场效果不参加竞价。每轮竞价后双方各提交一次完整技能计划，齐备后同时更新公开指向。

三轮共翻三条新效果，加开场一条共四条；后续牌的身份在翻开前不可见。第三轮配置锁定后不再出现效果、装备或技能调整，只进行下注、弃牌、摊牌。

## 八条效果的卡面

| 效果 | 一句话规则 |
| --- | --- |
| 迁流潮汐 | 转移力量时，转出多少，接收方就收到两倍。 |
| 援助扩散 | 每当收到队友的强化，右邻也获得同样一份。 |
| 屏障回响 | 挡下多少敌方削弱，就给左邻多少力量。 |
| 代价熔炉 | 技能实际付出的力量，全部加到它下一笔强化上。 |
| 缓流闸门 | 主阶段每笔强化只先到账1点，其余留到收尾。 |
| 余温护场 | 每次获得己方强化，同时获得等量护场，抵挡之后的敌方削弱。 |
| 弱者收礼 | 己方强化总是流向当前力量最低的友军。 |
| 逆向祝福 | 己方强化改为削弱相同位置的敌人。 |

左右邻居绕回另一端。护场累计在本手中，实际抵挡时消耗。最低力量并列取左位。

迁流明确是**付5收10**，不是要求付10。实际只转出3就收6；独立额外增益不翻倍。例如狂战士“转移2，另加2”在迁流下付2、队友收4+2=6。吸取按实际穿过防护的量计算。普通费用、凭空强化及把削弱改打另一个目标不是力量转移。存款延迟释放本身不再次翻倍；改给另一个受益者是新的转移。

一些旧卡已改成明确的“转移＋额外增益”文字及配对支付/收款事件，避免付不起却照发整笔力量。金库守卫的起始放款则明确是支付启动费用后创造贷款额度；实际收回本金再分配时属于转移。

## 配合与适配

三高应保有较多可行路线，三低保留少量明确的翻盘方向，不通过普遍补偿低数字抹平原数价值。场地倾向是设计假设，不是额外的牌型加分条件，也不是测得的胜率。

- 三高/多中高：扩散维持多条有用接收线；回响和护场巩固邻位；熔炉利用能实际支付的资源；闸门保护大笔收款。反复抽取时，高数较不容易付空。
- 三低：迁流尝试借敌人或多段转运的资源；逆向祝福用强化输出压低敌人。路线可能被截流、防护或目标改动破坏，不保证能救。
- 高低混合：弱者收礼提供明显的角色与数字分离路线，也可通过先付出代价争夺收款。它不是“三低专属奖励”。

每条效果另有角色类别、另一种用途及反制线索，保存在 `FIELD_FITS`，供说明与读牌提示使用。提示不得把这些倾向当成确定暗牌。

## 统一结算细则

源头装备先改变技能输出，熔炉接着加入已支付的成本；弱者收礼先调整目的地，逆向祝福再转换效果。之后闸门先延迟超额增益，再由接收装备、基础能力和主动监听技能处理。主动监听按位置从左到右，同位置按公开先手排序。

每条转移路径只访问同一节点一次；源头装备不会因改道被重复放大。场地直接创造的增益及其即时派生链不再次触发场地，仍可被人物/装备处理；之后独立产生的技能事件照常处理。这样不需要在每张卡上重复写一长串次数上限。

保留实际到账、实际支付、真正格挡与暂存的区别，结算轨迹逐步记录。场地支持组合不代表组合必然赚钱，必须同时计算对手所得。

## “常规/妙招”的评估口径

常规指顺着场地、人物和装备直觉形成的排法，不定义成数字排序。复盘先写直觉路线，再找反直觉但能解释的更优路线；“看到后觉得妙”仍需人的判断。算法可以筛选场地响应和反事实改进，不能把这两个指标改名为“天才比例”。
