# 意图实验模式 v2：输送链与可读场地

本版独立于旧数字模式前端。这里只修改纯代码规则、策略和测试工具，不能把浏览器里的旧页面当成本版体验。历史 v1 报告不代表本版表现。

## 六步教程

1. **选人、配数。** 九个人物候选允许重复，同名也是独立实例。人物、原数分别排位。基础场地先根据各位置原数改变起始力量；逐个排列预览，不必凭卡牌稀有度猜强弱。
2. **设置唯一技能。** 每人只有一个主动技能，默认关闭。开关、操作类别、目标公开，身份、具体效果、模式隐藏。箭头是作用关系：指友方可能是支援，也可能是抽取、换位或承伤。
3. **装备是一种承诺。** 没有基础加力。前三轮各一次机会，可先跳过；付2后必须从三件中选一件装入空位。没有替换轮。装备改变效果的输出、路径、防护或时机，不保证本局有收益。
4. **沿公开关系读牌。** 看到蓄能器，考虑自身强化、队友支援和装备转运三种入口；看到集束冠，观察其他位置是否会产生增益；看到左接导线，把箭头目的地再向左追一格。始终保留被迫装错、隐藏模式和诈唬的可能。
5. **为场地安排力量。** 技能及收尾结束后，生效的附加场地按 F1 至 F6 的固定公开顺序处理。每张先冻结双方力量，再同时结算。后一张看到前一张的结果。场地不是技能，不触发装备或技能账本。最后仍按三条固定对位的胜线数判胜。
6. **信息更新后下注。** 每轮双方各提交一次计划，齐备才同时公开，不能盯着对方改来改去。第三轮结束锁定。看出两条线很难救时，弃牌仍是合理行动；并非所有弱牌都应该翻盘。

## 场地提供的不同布局理由

基础场地 A1–A6 继续只看位置与原数；附加场地现在看战斗后的力量，而非又给某种原数加分：

| 场地 | 可尝试的路线 | 对手可读的线索 |
| --- | --- | --- |
| 落差回流 F1 | 集中强化一个位置，再由场地养最低位 | 强化汇聚点可能不是最终唯一主力 |
| 胜势接力 F2 | 给右邻的供体制造足够对位余量，最多转3 | 装备、箭头集中在其左邻时，右路也有威胁 |
| 阶梯共鸣 F3 | 通过代价或转移把力量整理成递增、递减 | 调整中位过高、过低都有代价；原数顺序只是起点 |
| 侧翼增援 F4 | 在弱敌对位用小数取得余量，补另一条落后线 | 原数最大者不一定是供体，应比较对位关系 |
| 败阵掩护 F5 | 主动输掉一条线，保留可支付力量向左送援 | 受压位的左邻可能获益；把它打到零又会切断资源 |
| 桥面张力 F6 | 中位集束后分给弱边，或在强边供能给低中位 | 中位与两翼的相对力量决定流向 |

场地转移不会凭空补足付不起的力量。每张最多转移3（败阵掩护每位最多2）。双方向规则相同，不能只算自己的奖励。阶梯共鸣是有条件的新增力量，其余为实际力量转移。

## 新增或修复的配合入口

以下是设计路线，不是经过总体样本证明的“天才组合数量”：

- 支援进入隐修士，再转到队友蓄能器；技能目的地与最终收款人不同。
- 无瑕刺客交换自己与队友的增益收款点，原本的自强也能变成跨线支援。
- 折射棱镜拆分大笔增益，接入两个独立接收节点；同时也可能增加被截流的入口。
- 侧接导线按位置绕行，能从最左接到最右，位置本身有成本和收益。
- 痴情骑士先接队友攻击，再按自己实际受损向另一敌位反击；防护会降低反击输入。
- 噬铁软泥与余波罐回收真实技能代价，支援型阵容也有输入，不再仅靠对方打中防护。
- 先用人物改变力量分布，再借 F2/F4 把“对位余量”送往不同位置。
- 有意保留一条落后但未归零的线，借 F5 支援其左邻。无资源的弃线不能免费供能。
- 用转移、代价、延迟强化修成阶梯，而非只能抽到顺序合适的原数。
- 场地公开顺序形成二次分配，但不会进入无限技能触发链。

同一原始效果可以穿过多个转移节点；同一节点每条路径只访问一次。源头增幅只计算一次，不能每转手一次就再次放大。主阶段限制、每手容量、暂存到收尾等边界仍保留。

输入争抢顺序也属于规则：接收位置的蓄能器及储能基础能力先处理；随后主动监听技能按来源位置从左到右处理，同位置按本手公开先手打破平局；最后处理其他接收装备。不能假定“自己改道一定先于敌方截流”。交换是双向的，下一笔送给另一端的增益也可能被送回来。

## 本轮验证口径

使用新版本文件名保存200桌状态机与5桌模型决策，旧1000桌不覆盖。模型只接收合法观察，提前写概率与理由；隐藏真值只在结算后由评估器读取。

重点区分：机制能够执行、非常规布局有独立样本优势、公开信息改善预测、公开信息改善行动，以及真人觉得惊艳。这五项不能互相替代。当前仿真每桌是一手独立的100筹码对局，不是多手打到破产的长局。
