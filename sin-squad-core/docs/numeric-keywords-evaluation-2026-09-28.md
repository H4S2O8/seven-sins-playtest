# 数字牌桌关键词重构与评估（2026-09-28）

## 实现范围

- 人物候选改成有放回独立抽取。9 张候选可有同名，能选两张乃至三张相同人物；选牌、AI、拖拽排位、重抽与存档均按每一张副本处理。
- 29 个人物中 16 个有关键词，3 个有双关键词；24 件装备中 13 件有关键词配合，共 11 类关键词。简单人物仍作为理解和估算的锚点。
- 全部 24 件装备、全部三个档位均有无条件基础力量。附加能力可被沉默/封印、护盾等规则克制，并非保证每次都有高收益。蓄能可接收自身、队友、装备、遗赠和共鸣的增益；不是只用来躲截流。
- 激怒支持敌方削弱、己方牺牲和增益被截流。激励数其他队友的不同关键词，统御认护盾/护送队友，结盟认人物与装备合计的不同关键词。
- 同一个位置的同名关键词只取较强值，不增加次数；不同位置的同名人物独立触发。控制使用同一快照，追猎使用同一快照，衍生增益不会再递归共鸣或截流，所以没有无限连锁。
- 结算：环境→控制→遗赠与阵容关键词→人物→装备→激怒/蓄能→追猎→胜利规则。追猎发生在激怒之后，不再回头触发激怒；卡牌详情和教程明确说明。沉默人物不关闭装备，人物遗赠在沉默下仍触发。
- 锁阵后不能改位置。看出对方克制时，行动仍是下注、跟注或弃牌，没有新增补救换阵窗口。

## 前端、教程与 AI

直接提取朋友主模式的 `cardShell`，两个模式共用实体卡外壳、正反面、厚边、卡框、卡背与光照。复用原有角色立绘、房间素材和颜色变量。数字模式重新排桌面层级，去掉每格状态说明；卡面写人话，公式放详情；装备增加图标；人物与数字分别拖拽交换，点击交换作为替代。手机操作区固定在底部，装备候选横向浏览。结算逐位翻牌、数字变化，可重看。

教程为 7 页、随时跳过/重看；词典按需展开，覆盖重复人物、原数/力量、沉默/封印、装备费、关键词顺序、加注/全押与结束条件。没有要求先背完所有关键词。

AI 用实际的新结算器评估选牌、排位、装备、表决和下注，并更新装备的软线索及重复人物计数。沿用价值下注、试探、诈唬、防守、弃牌等策略状态，三个性格参数不同。它只读公开信息和自己的观察层。

边界：每次只采样 6 个对手假设，不学习真人的长期习惯，不是 GTO。状态多不等于聪明。已有固定种子测试检查隐藏信息隔离、合法动作、存档重放和筹码守恒。

存档升级到 v2：新规则和重复抽牌改变了种子重放，旧 v1 局不能直接恢复；旧浏览器记录没有被删除。新版局可以刷新续玩。

## 模拟口径

运行：

```sh
npx tsx scripts/numeric-evaluate.ts
npx tsx scripts/numeric-synergies.ts
```

主样本是 1000 个完整独立手牌（每手从发牌到弃牌/摊牌，双方重置为 100 筹码），不是 1000 张打到破产的长牌桌。另做 400 手对旧“首牌、跟注、首装备”基线，交替座位。固定种子 700001–701400，生产默认六样本 AI。每动作检查总筹码 200，每手设 300 动作上限。

统计器只在结算后读取真值；没有把对方暗牌传给 AI。模拟能检查机制、策略行为及出现频率，不能客观测出真人觉得好不好玩，也不能凭自博弈评定所有卡牌强度。

旧版与新版同时改变了卡牌、AI 判断及抽牌方式；下方比较是两个版本的描述性结果，不是单一改动的因果实验。对弱基线的胜率不能用来排序两个不同规则版本的 AI 水平。

- 数字低/中/高档位：只用公开构成 63.5%，加入装备后 69.6%；旧版是 63.5% → 72.7%。
- 有装备的 1146 个位置：63.2% → 72.4%。
- 具体人物：只猜训练中最常见人物 8.8%，加入装备频率后 10.2%。

装备有信息，但仍然远不能可靠猜出具体人物。通用化降低了数字绑定，也没有自动换来足够强的人物识别。这里只测简单分类器；没有证明更强推断器的上限，也没有测真人或精确数字命中率。它来自同一套 AI 的不同种子，换真人策略或故意反装，准确率可能变化。

## 配合的计数方法

当前整理出 **9 类小配合/反制互动、4 条多段配合路线**，这是机制目录，**不是穷举的卡牌组合总数**。同一种机制可由多个人物/装备提供；不同路线可以重叠，不能把下面数字相加当成独立配合数。

小配合与反制互动：支援→共鸣、强化→蓄能、吞食→遗赠、护送→护盾、不同关键词→激励、护盾/护送队友→统御、双关键词→结盟、领先→追猎、减力/截流→激怒。

多段路线及已通过的确定性用例：

1. 食腐鸦在左，低数饕餮带蓄能器：吞食触发遗赠，赠力进入蓄能，末段释放。
2. 中位双子供能，其他位置带传能滑轮和蓄能器：支援触发共鸣，衍生支援继续供能。
3. 中位收藏家带关键词装备，侧位交际花，另一弱位带蓄能器：结盟触发侧位共鸣，弱位收集支援后释放。
4. 护盾/护送队友配僭王＋猎王印：统御抬高主力，主力领先后追猎另一弱位。

## 对之前问题的回答

**好玩吗，有潜力吗？** 我的判断：有潜力，比旧版更像可组队的下注游戏，值得继续做真人测试；现在还不能说已经很好玩。模拟不是满意度调查。真正的亮点是“我看见你装这个，于是愿意为这个判断下注”。如果玩家看不出大致强弱，再多关键词只会让开牌像宣判。

**策略是什么？** 先按本手胜利规则选赢法，再决定数字和人物的对应关系。中央规则保护关键位，最低线规则避免短板，双翼规则可主动放弃中路资源。组队时决定单核追猎、分散支援、蓄能抗截流、吞食遗赠、关键词多样性等路线。锁阵后用公开装备与下注成本修正判断；强牌取价值，弱牌止损，偶尔诈唬。不能把“高数字”当成万能胜率。

**是不是纯比大小？** 结果仍然是比最终力量，这是模式定义；但并非只比发到的三个数字。人物配合、控制、装备、位置和胜利规则会改写胜负。反过来，原数总和与胜负关联不高，也可能意味着机制太难估算；不能只凭这一个指标宣布深度足够。

**能博弈、读数字和人物吗？** 有隐藏信息、公开装备信号、下注成本、弃牌与诈唬空间，具备博弈结构。现在更能猜“可能走哪条路线”，远不能稳定猜出具体人物或精确数字。通用装备让更多队伍能用，同样会稀释装备与某个数字之间的绑定，这是实际取舍。精确人物分类仍弱，不能宣称“读牌目标全部实现”。

**能认知自身强弱与克制吗？** 比原先全是公式更清楚：护盾挡控制/削弱，护送保邻位，截流针对强化，蓄能保护有限容量，遗赠和保险缓解沉默，追猎把强位优势转到另一位。仍需学习规则、练几手建立尺度。保留随机场地/胜利规则、候选和装备抽取；结算本身确定，便于复盘。学习成本本身不当作缺点，问题在于学会后能否稳定做有意义的判断。

**配合多且容易拿吗？** 小配合有多种替代组件，确实比专门找两张固定牌宽；多段组合仍需要位置、数字、装备机会和存活到摊牌，不能称为随手就有。重复人物增加了另一种组队方向，但同名关键词不叠次数，双同名也可能牺牲激励需要的多样性。这是短手牌中的有限连锁，尚不是跨几十轮成长的构筑引擎。

**人物和装备设计好吗？** 已经有真实的机制变化，达到本轮的数量标准；还没达到成熟卡牌游戏的整体质量。基础力量消除了条件不满足时整张装备空白，但不等于每件装备都值得花费操作费。关键词出现率、选牌集中度和装备线索强度还需要后续平衡与真人验证。不能用“11 个关键词”代替评价。

**比小丑牌、炉石、酒馆战棋、杀戮尖塔更好玩吗？** 现在没有证据支持这个结论，我也不会这样评价。我的主观判断是目前的内容厚度、配合层次与完成度还不足以取代它们；这里值得发展的独特方向是短局的读牌和下注，而不是靠更多关键词去争同一种乐趣。和原来的攻防对撞相比，若目标优先是看线索、估强弱、敢下注，我倾向继续打磨单数字版；若更看重战斗过程与连锁表演，原版的空间更大。没有做真人同条件对照，不能声称单数字版已客观胜出。

## 人工试玩与限制

实际浏览器验证：同名候选分别选取、两张攻城锤手同场、拖人物和点击换数字、刷新续玩、锁阵、电脑主动下注、跟注、付费装备三选一、安装后公开、表决、暗标、过牌、跨轮、摊牌、逐位翻牌重放、原模式卡牌渲染。375×812 手机宽度和 1366×900 桌面检查没有页面横向溢出，操作区留在底部；控制台未见错误。触屏拖动尚未在真实手机硬件上验证，点击交换已验证。

本次没有把有限的人工试玩或确定性测试包装成长期平衡结论。接下来最有价值的是让未参与设计的人试玩，记录他们下注前预测的强弱、预测依据与开牌后的理解，而不是继续为了关键词数量加规则。

验证命令：`npm run typecheck`、`npm test`（157 项）、`npm run build:web` 均通过。重复选牌的 CI 冒烟样本限制为 8 个种子；1000+400 手分析是独立脚本，不挤占常规测试的时间预算。
