# 数字模式 AI 修复与 1000 手评估

> 历史基线：此报告对应关键词重构前的版本。当前脚本已更新；新版数据与复现说明见 `numeric-keywords-evaluation-2026-09-28.md`。

## 口径和复现

运行 `npx tsx scripts/numeric-evaluate.ts`。固定种子 700001–701400，生产默认六样本 AI。
主样本是 **1000 个独立完整手牌**（发牌到弃牌/摊牌结算，每手双方重置为 100 筹码），不是 1000 张打到一方破产的牌桌。额外 400 手轮换座位对战旧策略。
所有决策只读取己方 observation。统计器在结算后读取隐藏真值，做离线准确率评估；这些数据没有传给决策器。
每步检查筹码守恒，300 步上限，1400 手均结束，没有非法动作或守恒失败。耗时 129.964 秒。
摘要 `reports/numeric-1000.json`；逐手原始记录 `reports/numeric-1000-hands.jsonl` 本地保留（约 4 MB，不纳入 Git，可重新生成）。

### 装备能不能帮助读牌

前 700 手训练装备与数字档位的条件频率，后 300 手测试简单朴素贝叶斯分类器。基线已经使用公开的高/中/低构成；新增信息只有该位置的装备种类。平票预测固定取较低档，两种方法一致。

- 全部 1800 个位置：只用构成 1143/1800 = 63.5%；加装备 1309/1800 = 72.7%。
- 其中 1034 个装备位置：62.7% → 76.4%。

说明装备有真实信号，但没有证明能精确猜到数字或人物。样本来自同一批启发式 AI 的不同种子；人为反向装备、不同策略、换牌习惯都可能降低准确率。已知三张全高时，本来就不用装备推断，不能把这部分算成装备的功劳。

## AI 的改动和边界

- 独立 `NumericAgent`，不持有 Table，不读对手真实数字、人物、候选装备、未公开安装或暗标。
- 按选牌、重抽、排位、价值下注、试探、诈唬、防守、弃牌、装备、表决、暗标分支决策，保存每手选牌计划和独立随机状态。
- 对公开数字构成采样，对装备信号做软加权，再调用实际结算器评价候选；三个性格有不同下注阈值、风险容忍和注额。
- 改掉首张保留、固定排位、第一件装备、随机表决、永远跟注。
- 六个对手样本仍然粗糙；人物假设没有完整模拟对手的选牌偏好。没有跨手学习对手，也不是 Nash/GTO 求解器。下注历史主要通过公开统计及跟注成本进入判断，没有完整的行动范围贝叶斯更新。
- 每手主动下注/加注最多两次是控制复杂度的启发式，真人可研究其规律。内部状态数量不等于策略深度。

## 游戏设计判断

### 好玩吗，是否只是比大小

有可玩的短局决策：根据公开胜利规则挑人物、配数字、选关键位置，判断装备线索，再决定投入或止损。不是简单抽三个大数字就赢。
但目前仍是原型水平：大多数技能是条件加减力量，选择常集中在开局，后面反复下注、拿装备、表决。复杂文本不自动转化成精彩选择。模拟不能测量真人乐趣、留存或疲劳。

### 当前策略

1. 先按本手胜利规则分配资源：中路、边路、总和、最低力量、逆转线不是同一个目标，别默认总和最高就最好。
2. 低数字可搭沉眠巨像、镜中人、狂战士等，高数字可搭孔雀、无瑕刺客；支持位优先考虑邻接和中间位置。
3. 以公开构成作初始范围，装备作修正：厚衬背心提示低值，磨刀石提示高值，夹心垫提示中间低于两边。均是倾向，不是身份证。
4. 跟注看成本与奖池，不仅看“我好像有配合”。强势时加注，弱势面对大注退出；诈唬需要对手会弃牌，不能无脑推。
5. 花装备费之前看关键位置是否仍有改善空间。多付一次费不会必然拿到有用装备；替换装备还会降档。

### 是否达到预期

| 期待 | 判断 |
|---|---|
| 看装备对数字有感觉 | 部分达到，档位预测得到增益 |
| 看装备猜具体人物 | 较弱，多数装备只关联数字条件，缺少人物/流派独有信号 |
| 知道自己大概多大、克制什么 | 数学上可以，但场地、胜利规则、额外效果、原始数字条件增加理解成本 |
| 有随机性 | 有，发数字、人物候选、装备候选、场地和规则；固定输入后的战斗确定，不靠临场暴击 |
| 有博弈 | 修复 AI 后有下注、弃牌和不完全信息博弈；尚无证据说明深度足够 |
| 读出对手后能反制 | 明显受限：人物和排位在装备公开前已锁定，读牌后不能换位，只能通过下注、装备和表决回应 |
| 多套大配合 | 不足，主要是条件数值叠加，缺少持续成长和连锁引擎 |

### 配合数量与获取

内容有 29 人物、24 种装备（每种三个强度档，不能算成 72 种独立设计）。任意两张可同时生效不能都算“独立配合”。这里按可解释、能指导选择的路线列 **10 类代表性小配合**，不是宣称穷尽全库：

1. 沉眠巨像 + 低数字 + 厚衬背心：低值补偿。
2. 孔雀 + 高数字 + 磨刀石：高值强化。
3. 狂战士 + 逆差线圈：落后对位时反超。
4. 镜中人 + 低数字：补齐对位差值，省高数字给别处。
5. 牵线人 + 静默保险：自沉默换装备收益。
6. 牵线人 + 封口钉：沉默对位后加力。
7. 饕餮 + 左邻静默保险：牺牲左邻人物效果，转为装备补偿。
8. 收藏家 + 多位置装备：横向装备收益。
9. 双子 / 痴情骑士 + 关键相邻位置：支援决定规则要求的位置。
10. 冬眠熊 + 过牌 / 豪商 + 投入：行动资源与力量关联，代价是过牌机会或筹码风险。

这些类内部存在差异，第 4、9、10 类包括“人物与数字/行动”的小配合，不全是两张卡的组合。不能拿它们和成熟游戏的完整流派等量比较。
能举出两类多部件方案：沉默环境 + 多位静默装备 + 静默胜利规则；中路支援 + 高值结构装备 + 边路优先胜利规则。它们依赖场地/规则且多为加法堆叠。若“大配合”严格指跨轮滚雪球、连锁触发、改变玩法的成型引擎，当前没有这样的机制（0 类），而不是“有几十个大流派”。

获取概率：指定人物首批出现 9/29 = 31.0%；两批不重复候选总计见到 18/29 = 62.1%（不保证还能回头选第一批）。指定装备单次三选一出现率 3/24 = 12.5%；连续三次独立候选至少见一次为 33.0%，需先付费且手牌要持续到那时。理想化“指定人物 + 指定装备”约 10.2%（首批人物）至 20.5%（两批都能利用的上界），还没扣位置、数字、提前弃牌等限制。样本每人平均只有 1.628 件装备，也说明完整三件套并非惯常体验。

### 与四款成熟游戏比较

以下是设计判断，不是用户实验结论：目前不能说更好玩，整体完成度和可重复探索的空间明显不足。

- 小丑牌：本作缺乏同等级的成型后爆发与改变打法的组合；其官方定位本就强调 joker 和大组合。https://www.playbalatro.com/
- 炉石传说：本作保留下注与隐藏阵容的特色，但每手锁阵后连续出牌、资源交换、局面修正的机会少，尚未做到同等级互动深度。这是对当前代码的比较判断，未评价特定版本平衡。
- 酒馆战棋：本作节奏短、筹码心理战直接，但缺少多轮持续招募、调整、成长的构筑弧线。官方基础玩法说明：https://hearthstone.blizzard.com/en-us/news/23156373
- 杀戮尖塔：本作缺乏跨战斗牌组与资源规划，难以提供同等级的长线决策。官方游戏说明：https://www.megacrit.com/press-kits/slay-the-spire/

最值得保留的是“公开装备透露有限信息 + 隐藏人物 + 下注”。优先解决读牌之后缺乏调整窗口、人物信号不鲜明、配合普遍只加几点这三件事，比继续增加规则数量更有效。未擅自改变牌池和核心玩法，以免把 AI 修复与新平衡混在一起。
