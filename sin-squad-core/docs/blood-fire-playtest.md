# 血、火与被遗忘之名：本次可玩稿

第三个入口已从旧的数字模式换成新牌桌。它复用原牌桌的实体卡框、立绘、房间素材和选牌视觉，另外实现按刻行动的战斗结算；近战卡片冲撞、远程按阵营颜色发射球，演出速度可选，跳过演出不改变战报。

已能完整走通：每人一张秘密底板、三轮公开人物密封竞拍与选牌、24点生命的秘密分配与排位、技能开关/指向/抉择、三轮场地候选竞拍与采用/保留、逐轮下注、自动战斗、胜负分池。对手用分阶段状态机决策，不读取玩家隐藏底板或布阵。新牌桌目前是单局试玩，刷新不会恢复进度。

阵容说明不需要安装辅助轮：始终显示三人的预计首刀、已开启技能、底板和场地、可指出的配合条件。合拍、快攻、连锁、干扰辅助轮只增加建议，不改数值，也不窥探对方暗牌。详细说明采用展开的大字层。合击与少量自然配合在真实事件触发时爆出名字。

**范围边界：这是机制试玩稿，不是完整平衡版。** [设计稿](blood-fire-v2-design.md)的204条命名路线还是设计清单，当前引擎没有逐条实现/验证；已经可触发的命名演出以同刻合击及部分真实资源转化为主。30人、6底板、20场地均可抽到，但部分复杂效果仍需与设计稿逐张对照，不能据此称全部语义已覆盖。当前对手会看公开牌和场地调整出价与下注，但还不是经过大样本调优的高水平博弈对手。辅助轮建议是确定条件与局部启发式，不是胜率或配合概率。

验证：`npm run typecheck`、`npm test`、`npm run build:web`，以及浏览器从第三入口走到选人、布阵、场地、下注、揭示和战斗。`npx tsx scripts/check-blood-fire.ts` 是场景差异探针：报告“未观察到差异”仅代表脚本使用的几组阵容，不等于技能无效。任何平衡或“好玩”结论仍须独立实测。
