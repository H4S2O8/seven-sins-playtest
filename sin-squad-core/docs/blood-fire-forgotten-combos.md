# 四接口版 · 204条命名配合路线（含4种合击）

仅适用[四接口v2](blood-fire-v2-design.md)。旧路线见[v1归档](archive/blood-fire-v1/combos.md)。以下是手工因果设计，未做战斗可达性或平衡验证；没有把旧封印、换位、清火配合冒充新版有效路线。

每行列原生收益与成立条件。个别路线需要对手提供受伤/破盾机会，不能当成拿齐就必成。三人链包含两人链时，算延长了作用路径，不宣称统计独立。相同参与者若出现两次，必须使用不同能力和资源路径，单纯换个位置不增加数量。

## 通用配合章与奖励

人物、底板、场地均可作贡献来源；敌人只提供窗口，不算友方贡献者。同一人物的两段自带效果不能独自拿组合章。

事件从产生到使用保留来源。只有实际扣血、有效治疗、盾实际吸伤/消耗、有效改变行动时刻等才成立，不能只凭成员在场颁奖。所有章取消每场次数上限；新事件反复满足条件就反复颁奖，同一事件满足不同章也可叠加。只去除同判定器对同组输入事件的重复投递，不限制真实连锁。

奖励在根事件当前波次的死亡与接战处理后发放：盾1给当前前位；疗1给最低生命比例活人，同率靠前；拍1使当前前位下次行动提前1。奖励产物可接基础、底板、场地和后续章。防止零时间、零净资源消耗的无限环，不用“奖励不触发奖励”切断所有连锁。

**本表机制路径仍供参考，但旧文字中的每场两次、三次、一次奖励及禁止奖励连锁等限制全部失效，以主设计当前触发政策为准；204条路线的量化收益须重新核验。**

合击细则以主设计为准：每次同步可再次领奖，三人同时计算三组不同配对和三重奏，技能伤害不凑普攻人数；死亡者的已发攻击计参与但不领个人奖励。批次结束、下一刀排定后发放，奖励导致的后续同步照常领奖。

“抢先”“改善存活”须局部反事实核对：移除那次贡献时，击杀或存活时间确实不同。做不到可靠核对时先显示战报、不颁该章。所有奖励都是小附赠，不能拿奖励反过来证明原生配合成立。

|204 三席共鸣|B05+B02+N01|卫士放前位并关闭开战技能，两名远程同刻出手；三人首刀均在第8刻，触发三重奏、两次交叉掩护及一次齐射续援。|

这些不是固定配方奖励。相同事件链可以由别的角色完成；实战显示已命名路线或通用章名，收藏记录贡献者。模拟要分别记录启动率、有效量、相对消融收益、实际出现率、是否依赖敌方特定行为。

本轮静态检查不执行自然语言。尤其涉及“先出手”“恰好破盾”“实际多活一刀”的路线必须由后续引擎验证。无法达到条件的应删改，不把200这个数当不可动的成绩。
