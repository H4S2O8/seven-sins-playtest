# v2 复核：200桌状态机、5桌模型

## 结论

**只解决了一部分。** 装备不再有保底加力，三选一确实会尴尬；公开信息对行动有有限正收益；场地能够改写胜线。但“约三分之一有令人惊艳的非常规布局”没有得到支持，预测器仍过度自信，复杂交互仍容易算错。不能据此宣布好玩，更没有证据胜过小丑牌、炉石、酒馆战棋或杀戮尖塔。

本轮是200手独立的100筹码对局（种子972001–972200），不是200场打到破产的多手长局。样本没有按结果筛选。约287秒；20项针对规则的检查通过，核心 TypeScript 检查通过。旧1000手属于不同版本、不同种子，表中仅作历史背景，不能当严格因果对照。

## 状态机结果

| 指标 | 本轮 | 说明 |
| --- | ---: | --- |
| 弃牌结束 | 78/200，39% | 34早弃、44中途弃；仍高于约30%目标 |
| 摊牌 | 122/200 | 22平局 |
| 付费装备候选 | 280次 | 每玩家平均0.70件，依旧不会人人拿满三件 |
| 三件均不能改善当前方案 | 47/280，16.8% | 相同信念样本下、未重新优化技能的代理；不是三件绝对无用 |
| 原数总和更高者赢 | 45/88，51.1% | 仅非平局且原数总和不同的摊牌；不是纯拼数字总和 |
| 非常规初始布局有独立样本优势 | 7/100 | 其中6例优势受技能支持；没有达到约三分之一 |
| 预测相符候选 | 95/200 | 仅摊牌可核对，不能直接称为玩家正反馈 |
| 出乎预测候选 | 61/200 | 其中41与技能/装备消融有关；预测器失准混在其中 |
| 可改进方案落地后结果更好 | 15/140个审计机会 | 当时合法信息先选择，之后才与实际对手比较；不是15次真实懊恼 |

布局审计只在初始排位比较基础场地、人物与技能，尚未建模后续装备及场地表决。因此7%不能用来判定新附加场地完全无效，也不能把后续场地改胜负直接算成非常规初始布局成功。这里有实质测量缺口：状态机初始排位也尚未把未表决场地的未来收益纳入规划。

## 公开信息是否能用

1200个敌方位置预测：

| 可用线索 | 人物命中 | 原数档位命中 |
| --- | ---: | ---: |
| 场地与原数构成 | 36/1200，3.0% | 823/1200，68.6% |
| 再加装备 | 54/1200，4.5% | 844/1200，70.3% |
| 再加公开技能类别与指向 | 316/1200，26.3% | 823/1200，68.6% |

**指向能缩小人物范围；对数字排位的推断没有稳定改善。** 人物命中上升也部分来自技能目标形状的硬约束，不能全部归功于玩家式推理。

额外对已经跑过的对局做40个第三轮计划机会的等预算对照：保持自己牌、场地与搜索预算相同，分别移除或加入对手装备/指向。先选方案，再读取实际最终对手核对。34次改变方案；8次更好、4次更差、28次不变，胜=1平=0.5负=0的平均差为+0.0875。说明线索有一定行动价值，但样本小、对手后续计划固定，是反事实审计，不是新对局胜率，更不是闭环因果证明。

原始预测仍明显乐观：153次预测达到80%以上，平均预测93.1%，实际胜/半平权益63.1%。Brier为0.270；下注决策虽已收缩置信，底层信念模型仍没解决。不能把误判包装成惊喜。

## 新场地有没有真正改变局面

122手摊牌里71手至少启用一种附加场地。固定最终人物、装备和计划后移除场地作机械消融：64手力量改变、44手胜线分布改变、20手总胜负/平局改变。不能据此断言玩家在没有场地时仍会采取同一方案。

例如样本25的胜势接力：场地前甲[4,8,6]、乙[8,9,1]，乙赢两路。双方同时根据旧快照转移余量后变成甲[7,8,3]、乙[6,11,1]，甲反而赢两路。**这是实在的跨线改写，但“算得出来的翻转”仍不等于“惊呼天才”。**

## 五桌真实模型决策

由当前语言模型根据合法观察逐步选动作，没有调用状态机代选自己的动作。随机发牌，完整结束5手，共68次成功提交的模型决策。结果：摊牌1胜1负1平，自己早弃1手、对手早弃1手，合计净亏13.5筹码。样本不足以估计模型实力或游戏胜率。

- 第2手：看见敌右逆相片，关闭原本针对该位的孔雀，省下代价；最终赢了左右两路。但敌方中途也改了计划，不能把获胜全归给关闭孔雀。
- 第3手：低低低对低高高，敌人公开路线让截流目标可能落空，面对2筹码下注直接弃牌。这是不能指望全都救回的例子。
- 第5手：试图通过右侧交换者把左位支援送回左边，让中位自行蓄能。**想法存在，但判断错了。** 敌中位截流按源位置顺序先于己右位交换，先截掉3；交换又把后续给左的贷款送回右，实际力量[8,7,5]，输给[5,11,9]。保留旧路线的事后固定对手复盘为[7,11,4]对[5,10,9]，反而赢。这个对照使用揭示后的对手，只能定位错误，不能假称当时知道必胜答案。

第5手说明当前要学习的不只是关键词，还有争抢输入的处理顺序、每手额度以及双向路由对后续事件的影响。它能形成练习空间，也能造成难以预见的失误；没有真人反馈前，不能只把这叫深度。

## 后续真正需要解决的点

1. 初始排位要考虑已公开但未表决的场地及启用成本，不能只为当前基础场地做短视优化；现有布局指标也要覆盖这一点。
2. 读牌模型要更好地区分“支援、抽取、截流、延期”，并考虑对方也会优化，而不是继续用随机弱方案导致过度乐观。
3. 预览应明确展示输入先被谁争取、路线在哪一步改变。当前纯代码模块已有结算轨迹，但尚未接入前端；增加文字说明不能代替可视化预演。
4. 继续区分几种不同战略：改变供体、改变受益者、改变时机、操纵场地余量。现在这些路线能运行，但高质量组合的数量和可获得率尚未证明达标。

本轮按要求停止于200桌状态机、5桌模型，没有为了调出漂亮数字继续追加整桌测试。
