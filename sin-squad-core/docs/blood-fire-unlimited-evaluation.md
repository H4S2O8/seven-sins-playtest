# 不限次数触发：重新评估

结论：持续连锁值得保留，但现有奖励数值和全局奖励结构不能直接照搬。问题并非“触发次数多就不好”，而是同速阵容免费获得过多收益，以及部分奖励原样补回了再次触发所需的资源。

本次仅做规则审阅与可复现的局部代码实验，没有完整战斗引擎、没有200桌对局、没有AI胜率或人类好玩程度测量。没有修改当前卡牌规则；下列调整是建议。

复现：`python scripts/evaluate-unlimited-triggers.py`。
原始数据：[JSON结果](../reports/blood-fire-unlimited-probes.json)。报告记录被评估规则文件的SHA256，后续修改不能冒用本次数据。

## 1. 合击奖励量明显偏大

实验隔离C26～C29：三个单位均持续存活，打不死亡的靶子，不开技能、底板、场地及其他25章，运行60逻辑刻。近战统一攻3，远程统一攻2，近战按槽间隔6/8/10，远程6。奖励开启时按当前政策，所有配对与三重奏都计算、不限次数。

|前→后|不开合击的总伤害|开合击总伤害|额外生成护盾|额外生成治疗|奖励次数|
|---|---:|---:|---:|---:|---:|
|远远远|60|66|0|66|44|
|近远远|70|77|44|22|44|
|近近远|71|75|24|0|16|
|近近近|69|77|0|0|5|

生成盾、治疗不是有效防御，不能相加为等价生命，更不能推成胜率。满血治疗会浪费，实战有人会早死，60刻也可能长于多数真实战斗。此表只测规则给不同类型阵容的奖励倾斜。

但倾斜机制明确：远远远与前置近战的近远远均天然6刻同速；每次三重奏使下一轮变成5刻，同步不会自行散开。无需调速角色，就稳定重复配对奖。长期频率从每6刻变每5刻，提升20%；60刻窗口从10轮变11轮，不能把短窗口伤害+10%误当长期+20%的实测。

第一轮，近远远已经能得到两次交叉掩护共4盾、一次齐射疗2、一次三重奏。总生命只有24，这不是很小的添头。相比之下三近战自然行动6/8/10，不会每轮免费三重奏。

含义：这版很可能奖励“选到天然同速类型”多于“通过构筑调出合击”。是否强到压制其他阵容，还要含技能、生命分配、敌方干扰的完整模型验证。

## 2. 破盾奖励存在闭环风险，局部已经复现

局部模型启用：双方前位火线织工F08、后排余温修女F06，场地急燃E04，配合章碎甲抢拍C04。设前位各12生命、盾分别1和2，并由外部供盾来源提供可追溯贡献；一个2伤普攻作为种子打破2盾。

链条：破盾→织工施加灼烧→急燃变立即2伤→对面破盾→对面织工反击；C04给反击的一方前位补1盾，修女又把对面实际掉血转为本方治疗。补回的盾和生命允许下一次反击继续。

脚本按同层先治疗/护盾、后伤害的现有规则执行，发现第3波与第5波的生命、盾和待处理指令完全重复，且逻辑时间没有推进。事件是新事件，不能靠重复消息去重解决。

重要边界：这证明的是这个明确规则子集在给定合法数值局部状态下能不终止。尚未证明该状态在完整开局必然可达，也没有启用全部其他配合章；其他奖励可能增加盾而意外打断链条。不能把本例报告成“已模拟完整对局必卡死”。但规则组合必须独立有明确终点，不能靠另外一个奖碰巧救场。

消融结果：

- 关闭C04：4波内结束。
- C04仍奖励立即补盾：第3/5波出现重复状态。
- 建议变体“C04改为下一次普攻+1伤害”：4波内结束，双方各存+1伤害，等待未来攻击兑现。未限制触发次数。

这个变体只证明切断了该局部闭环，不证明消除了所有循环或已经平衡。关键是别把“破盾的奖励”立即变成同一个位置可再破的一份盾。

## 3. 正反馈不都需要截断

另测无名剧院P03与轻甲快行E12。外部提前让到期时刻10→9，剧院给1盾；轻甲先减1，实得0盾，不再触发提前。无次数上限也自然结束。

即使在单独标明的假设变体中取消轻甲的减盾，每次盾再提前1，仍会在到期时刻达到当前刻+1时结束。此例共9次有效提前、9盾，不发生同刻无限攻击。它有实际行动进度这一有限空间，不需要全场一次的限额。

因此应区分：可持续到下一次普攻的引擎、会耗完有限资源的长连锁、完全不推进时间也不耗净资源的闭环。前两者可以保留，最后一种需要改作用路径。

## 4. 牌池与读牌的影响

- 技能大多仍是单次，全球合击奖却无限持续。长局中奖励可能比“选哪个人的唯一技能”更影响战局，削弱公开人物带来的推断价值。
- N10每次普攻供盾、B03每次普攻治疗、F08每次破盾点火等持续发动机更值得重视；不能仅依据旧的单次预算给人物评级。
- 有些首次时机仍留在F01第一刀点火、N08第一次减伤、P06第一封信中。这属于牌面启动方式，但与取消“持续被动次数限制”的边界需要明确，不能让不同角色凭措辞获得意外待遇。
- 四接口让结果容易识别，却没有消除29章的达成与因果判定负担。满屏演出可以保留，但玩家需要看见启动者与主链，不需要在战斗前背完204条路线。
- 同步、错峰、延迟敌人仍有博弈潜力；全局天然同速奖励过高，反而会压缩这些选择。当前没有证据可宣称非常规布局约三分之一或204条全都可达。

## 建议顺序：保留不限次，改奖励结构

1. **先切闭环边。**优先把即时回补同一触发资源的奖，改为下一次攻击时兑现的伤害或其他不会当场原样循环的收益。已局部验证C04改下刀伤害能切本例，不增加次数限制。
2. **下调免费普适奖的单次数值。**交叉掩护2盾与齐射2疗先以1为对照试验；不断触发的视觉保留。减半是否足够尚未知，不能未经测试宣布解决。
3. **考虑把三重奏的无条件全队加速改为一次合击伤害，或把持续加速绑定某张发动机。**否则6刻自然同步会免费变成5刻自维持。两种都是待选方案，不在本次评估中擅自改定。
4. **强连锁由人物、底板、场地构筑出来。**让基础合击奖较轻，真正夸张的收益来自你主动争抢和部署的东西，仍允许不限次、叠奖与奖励接力。
5. **先跑包含死亡与干扰的完整小牌池。**比较四种近远程构成、开关奖励、旧/新单次数值；记录有效治疗/吸伤、击杀时间、各人死前出手数、调速收益和同速是否唯一最优。再谈完整胜率、200桌和实战好玩程度。

直接判断：不限次更接近用户要的连续爆发体验，但当前数值不能交付为平衡版本。我之前只去掉次数限制，没有同步重做奖励反馈结构，改得不够完整。应修正“免费、自动维持、原样回补”这三件事，而不是把触发次数上限加回来。
