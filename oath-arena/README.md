# 逆誓竞技场 / OATH · FALL

第一版可玩单人原型。对手是本地电脑，不是联网玩家。点击「开始教学对局」边操作边学习。

## 核心流程

1. 双方各40筹码，整局不补钱。兵种、效果牌、承诺分别展示10张，暗拍先选权，赢家付自己的出价。两人每次各取一张，共5次，因此每人5个兵种、5张效果牌、5张承诺。
2. 每场先秘密部署最多4人口的主阵，同时公开。第一名部署的单位为标记单位。位置和移动/站定指令锁定。
3. 根据主阵选择一张暗牌，可附带一个公开承诺。暗牌有成功/失败两个效果，失败不等于战斗被打败。
4. 从10条规则中暗选。同选免费；不同则在两个提名间进行一次封闭竞价。高价者付款，平价使用公开轮转优先权。0筹码仍能继续。
5. 秘密补阵至最多6人口，不能修改公开主阵。双方同时揭阵，自动战斗18秒或直到一方本场单位全部死亡。
6. 固定战场数据 → 分别判断成功/失败 → 揭晓暗牌 → 结算承诺。效果不直接在战后造成伤害。之后重新选人、布阵。
7. 伤亡永久保留，预备席本场不被攻击。消灭对方全部兵力获胜，不计分，不设固定五轮。

## 原型补充约定

- 效果牌使用后休息一轮，可以反复使用；承诺使用一次即消耗，无论达成与否。可以不作承诺。
- 效果牌与承诺共用本轮选择的收益对象；群体效果除外。对象死亡时自动转给存活者中人口最高者，再以剩余生命打破平手。无人存活则落空，不复活。
- 新强化从下一场起计时；预备席同样消耗持续场数。同名强化刷新时限而非叠加，避免无限滚雪球。攻击增幅、护甲、圣盾另有硬上限。
- 第5次交锋起「激战升温」：每增加一场，战斗内攻击+15%、治疗-10%，治疗最多减少80%。这是防拖局的公开暂定规则，不造成战后/预备席伤害，不改变消灭兵力的终极目标。
- 移动单位追踪最近目标，附近嘲讽可改变目标。站定单位不主动移动，也不会发动冲锋，但可以被击退/牵引。
- 规则数据在治疗前固定，相等时双方成功。显示和比较精度均为一位小数。
- 50条规则由25种指标的正反方向构成。特殊词条规则根据公开主阵过滤，但没有声称所有状态都具备双向翻盘机会。部分条目仍是用于测试收益、牺牲和布阵关系的内容基线。

## 内容与实现

- 30个可竞拍兵种：12种暂用美术原型，数值/词条组合区分30种玩法。
- 50张效果牌：26种底层效果的50种成功/失败配对。
- 50条法则：25种可核对战场指标的正/反比较。
- 50张公开承诺：不同阈值、比较方向及回报。
- 图鉴全部可搜索，支持卡面详情、伤亡与收益结算、战场数据审计。
- 教学为真实对局内的8阶段操作指引，不是预录视频；支持跳过、自动布阵和零价快速征募。
- 自动存档。战斗中刷新会回到该场开战前；其它阶段直接恢复。
- 随机种子只决定供牌、电脑风格等；同一布阵的战斗可重复，没有随机暴击。
- 电脑决策只读取己方信息和玩家公开主阵；出价提前生成，不读取玩家本轮报价。没有调用大模型、网络服务或用户账号。

## 文件与替换接口

- `content.js`：稳定ID、所有内容和效果数据。
- `engine.js`：纯逻辑、自动战斗、拍卖、判定、伤亡与效果。
- `app.js`：流程状态机、教学、输入、存档、电脑补阵。
- `art.js`：`ASSETS`注册表，单位插画、精灵/动画帧、背景、特效、音效挂钩。详见 `ART.md`。
- `style.css`：响应式卡面、布阵界面与教学。
- `CATALOG.md`：可离线逐条审核的完整180条内容，由工具从真实数据导出。
- `tests/`：逻辑测试、真实页面按钮操作测试、截图和测试报告。

## 本地运行

不需要安装运行依赖。安装Node后在本目录运行：

```sh
node server.mjs
node --test tests/engine.test.mjs
```

打开 `http://127.0.0.1:8937/`。可以加 `?seed=20260918` 重现同一初始牌池。部署到静态网站时只需HTML、CSS、JS、WebP素材及文档，不需要服务器程序。

浏览器QA脚本当前复用工作区已有的Playwright安装和本机Chrome。独立移植时修改导入位置及浏览器可执行路径。美术是暂用AI生成资产加代码特效；没有完成逐兵种手绘动作或正式竞技平衡验证。
