# 七罪暗队（Godot 4 可玩版）

当前版本已经接通一局完整主循环：暗队三选一组建、下注、配置操作、装备/效果三选一、公开效果、战斗回放、结算与下一手。

## 启动

双击项目根目录的 `PLAY_GAME.bat`，或用 Godot 4.7 打开本目录并运行主场景。

## 当前内容边界

- 人物选择：每个位置三选一；每个位置最多重抽一次；换掉的三名候选不会回池。
- 装备/效果：保留原有三个候选与六个己方槽位流程。
- 正式随机池只使用已有真实处理器的内容：84 名人物、69 张装备/槽效、18 个场地与 21 个公共效果。
- 未实现内容不会以空效果进入正式对局。
- 荷官使用统一比例的完整上半身图层，避免原先的横向压缩和分件拉扯。

## 验证

完整经济、Session、规则、战斗、装配、内容交叉检查和数据回归均通过；另有图形主循环测试从组队走到结算并开启下一手。
