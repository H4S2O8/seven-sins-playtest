# 七罪人物｜98人设计稿

遵循《00-战斗约定.md》，以下都是人物天赋，不是装备限制。每罪14人，编号固定；近远指普攻方式，轻中重甲仅是标签，与护甲R分别计算。无人物新增实体、交换阵位、复制整段天赋或使用真实筹码作战。

## 本页读法与执行补充

- 所有能力仅在正式战斗内判断；不提供开战前敌方隐藏面板查询。身份维持隐藏，主攻箭头按底座公开。技能效果可供推断，但不额外宣布角色身份。
- 「目标」指这次依公开箭头及底座替补规则确定的普攻目标。「基础」为人物卡面值，不含装备；「最大生命」可受其他效果修改。额外伤害仍打这次目标，除非卡文明确指定其他存活单位。
- 「普通普攻」不含额外攻击；只写「普攻」则包括额外攻击，但仍受底座的一层限制。伤害类型改变不自动附送同名状态，例如冰伤不等于冰缓。「命中前追加」并入本次普攻的伤害包；「命中后追加」是另一个伤害包，不产生新攻击命中事件。
- 多段普攻的每个命中段各有独立根，均可启动命中收益；「命中次数」逐段计数，「开始准备/完成一次普通普攻」按整次攻击计数。每段派生的转移、附伤、治疗继承该段根编号，同一效果在这一根内只发动一次；禁止继续安排额外攻击的标记随所有派生事件保留，不能经队友或治疗链清除。人物自带的明确冷却/次数上限仍正常生效，不另加隐形的整次攻击限触发。
- 派生准备时间向上对齐到0.1秒；派生伤害、治疗、护盾量向下对齐到0.1。临时A、R变化不改基础面板。忽略R最低算到0，不产生负甲加伤。
- 同比值选人时取较小编号；「最低生命比例」按当前生命/最大生命选。「其他队友」不含自己；没有合格单位时不转给别的人、不凭空获益。
- 每N秒事件首次在第N秒；每次状态的首次跳伤在施加1秒后，期限内按整秒结算。恢复不超过最大生命；「有效治疗」只算实际恢复生命。额外治疗与伤害同样遵循根事件触发限制。
- 本页新护盾均写明数值与期限；同人物同一天赋产生的护盾刷新而不相加，除非明确写「补入」及池上限。清除护盾不算伤害，但若清至0算护盾破裂；自然到期不算破裂。屏障仍遵守不可叠层。
- 护盾保留来源分池，消费/清除优先最早到期池，同刻取施加者编号小者；同来源刷新是以新量替换旧剩余量并重置期限，「新增长度」只计替换后的正差额。借盾等追踪的是指定来源盾实际吸收的伤害，提前清除或主动消耗不算吸收，已有偿债记录仍按原期限兑现。
- 同类持续伤害仍遵守总层数最多5，逐层保留施加者；添层未达上限则新增，已满只刷新时间不挤掉原来源。同名刷新期限作用于现存同名层。移除一层优先最早到期层，同刻取施加者编号小者；按来源缩短时只改相应来源层。没有实际新增层的刷新不算「被施加一层」。
- 此页「队友加伤」仅指队友来源直接提高A或该次攻击伤害的增益；队友降敌甲、减慢敌人或缩短我方准备不算加伤。「累计有效敌方伤害」只记对敌实际扣除的生命，不记护盾、自伤、溢出或友伤。
- 持续状态沿用底座；本页施加的灼烧/流血/中毒额外写明层数与持续时间。减慢准备时间统一取最强值。缩短准备的效果不能突破0.6秒间隔下限。改变T默认只影响下一次开始的准备，不重置当前普攻。
- 「每战一次」在实际生效时消耗。次数、资源和冷却不能跨战。沉默时不积累天赋计数、不新触发天赋；已结算的伤害不回滚，已发出的定时伤害/债务按期兑现，已有增益按自己的期限结束。复起遵守每人每战最多一次，天赋被沉默时不能新发动复起。
- 重复引擎没有未写出的全战次数预算：只要满足条件且冷却结束，就能继续存取、触发或循环计数。护盾/状态期限、单次伤害上限和存量上限不是累计产出上限；可以反复清空再补满。明确的开场弹药、首击机会、储粮、一次救命及退场窗口仍按卡文消耗，不自动再装填。
- 固定/元素伤害仍受通用减伤、护盾、屏障影响。「自行失血」遵守底座，不称作敌方伤害；特别写明「最低保留1生命」才非致死。来源为附加伤害时不能再安排额外攻击。下文次数上限之外仍适用每根事件一次、一层额外攻击。
- 本页事后阈值治疗/护盾均不能挽救同批已经致死者；只有明写复起可先于最终退场。若同时间戳多名己方对将退场敌人造成正数实际失血，均视为共同击倒者；要求「自己的普攻击倒」时本人在该批必须有正数普攻失血贡献，不靠先后顺序抢归属。
- 攻击「落空」专指目标已最终退场而本次尚未命中；底座允许改选替补的攻击正常改选，不人为制造落空收益。所有能力不改变三人的固定编号；友方支援和明写的附带溅射不改变主攻箭头。

## 愤怒｜WR01—WR14

构筑方向：承伤反击（01/02/06/12）、破盾破甲（04/10/13）、近战爆发与收尾（03/05/07/08/09/11/14）。

### WR01｜蓄痛拳手
面板：H112 / A10 / T2.0秒 / R2 / 近 / 中甲。
能力：受到敌方来源伤害而失血后，将实际失血的40%存为怒量，上限12；下一次普攻命中后清空怒量，追加等量物理伤害。每次追加后1秒内不存怒；自伤不存怒。
用法：把可控的伤害转移变成反击燃料；适合治疗续航，但厚盾会减少怒量来源。
弱点：无人攻击或被持续沉默时只是慢拳；高甲、屏障与打完即撤的爆发压低兑付收益。

### WR02｜护短刃
面板：H86 / A11 / T2.1秒 / R1 / 近 / 轻甲。
能力：其他队友被自己的当前目标普攻命中后，若自身存活且未定身跨位，向该目标发动一次60%基础A的物理额外攻击；冷却3秒。附加伤害不触发此反击。
用法：通过公开箭头选择正在打队友的敌人，形成护送反击；队友有屏障也能启动。
弱点：敌方转火本人或其他目标后失去反击；跨位定身与对方低频高伤攻击都克制它。

### WR03｜破缚者
面板：H104 / A13 / T2.4秒 / R1 / 近 / 中甲。
能力：每次开始准备时若自身有定身或准备减慢状态，清除定身并在本次准备中忽略减慢，且本次普攻命中追加5固定伤害；冷却4秒。不清除场地，不免0.4秒跨位代价。
用法：针对雪、泥和定身环境的突进位；用较慢的常态换取受限时完整的一次出手。
弱点：无控制环境不如专职输出；控制在其开始准备后施加，仍能限制该次攻击。

### WR04｜凿甲匠
面板：H100 / A9 / T1.8秒 / R3 / 近 / 重甲。
能力：普攻命中后，使本次目标R降低1，持续4秒；自身对同一目标最多累计降低4，重复命中刷新全部自身层的期限，R最低0。不同目标各自计层。
用法：物理集中火力的破甲先锋，自己先手后让高A队友兑现；不要求绑定罪名或装备。
弱点：零甲敌人和元素队里收益低；换目标或攻击被拖慢会让叠层断档。

### WR05｜燃血斧
面板：H118 / A14 / T2.6秒 / R0 / 近 / 中甲。
能力：每次普攻攻击前若生命高于最大生命的35%，自行失血6，使这次普攻全部改为火伤并提高6；不足条件则作普通物理攻击。
用法：以治疗资源换取穿甲爆发；适合恢复强但缺乏元素输出的组合。
弱点：不受击也消耗生命，残血时爆发关闭；禁疗、通用减伤和压低最大生命都会增加风险。

### WR06｜截痛卫
面板：H140 / A7 / T2.3秒 / R4 / 近 / 重甲。
能力：其他队友受到自身当前目标造成的伤害时，将其结算到转移步骤的30%转给自己；每秒接收上限10。本秒额度不足只转剩余额度；不再次转移。
用法：用一个公开箭头指定要牵制的敌方火力源，保护两名脆队友；接收盾和受伤能力均可利用。
弱点：自身低输出，接收伤害不能重算自身高甲；多来源分散火力或先杀本人能绕过保护。

### WR07｜继火人
面板：H94 / A12 / T2.0秒 / R1 / 远 / 轻甲。
能力：首名其他队友最终退场后，自身获得持续5秒的继火：T缩短0.5秒，普攻命中施加1层灼烧3秒；该队友尚未复起判定完成不触发，全战仅一次。
用法：为有明确退场节点的前排配置后手火力，保留残局反击机会；远程能及时兑现窗口。
弱点：队友都活着时无增益，若本人先倒下就浪费；不能以全队同灭换收益。

### WR08｜断尾枪
面板：H88 / A10 / T2.2秒 / R1 / 远 / 中甲。
能力：普攻命中前若目标生命比例不高于30%，本次普攻追加9固定伤害；同一目标仅能追加一次，全战最多3次。判定取命中前值，不因本次攻击刚好压线而追补。
用法：给擅长压血但缺最后一击的队伍提供收尾；根据箭头选择已经受压的目标。
弱点：恢复把目标抬过阈值或屏障挡住关键攻击时收益骤降；对满血强敌没有首轮优势。

### WR09｜裂阵锤
面板：H122 / A15 / T2.8秒 / R2 / 近 / 重甲。
能力：普攻命中后，若另外两名存活敌人都存在，分别对其造成本次普攻实际失血量的25%的物理伤害，每人上限4；每次普攻最多一次。额外攻击不溅射。
用法：保留主攻箭头的同时削弱敌方双后排，适配提升单次有效普攻伤害的配置。
弱点：对方只剩一名其他敌人便不溅射；主目标厚盾、高甲或低剩余生命都压低收益。

### WR10｜碎盾钩
面板：H98 / A9 / T2.0秒 / R2 / 近 / 中甲。
能力：普攻命中前清除目标至多8护盾，随后按实际清除量的50%追加固定伤害；冷却3秒。屏障不属于护盾，追加伤害仍会被屏障抵消。
用法：打开护盾型阵地，清盾与追加伤害是两件明确事件；可为队友制造破盾窗口。
弱点：无盾目标面前缺乏伤害强化；频繁小屏障比大护盾更能限制其固定伤害。

### WR11｜三拍雷槌
面板：H110 / A11 / T2.2秒 / R2 / 近 / 重甲。
能力：普通普攻成功命中累计到第3次时清零计数，并在本次目标处于存活状态时追加10雷伤；额外攻击不计数。每次雷击后至少隔1秒才可继续计数，之后可重新完成三拍。
用法：稳定三拍穿甲核心，适配缩短准备和保证命中的保护配置，不依赖自己挨打。
弱点：定身跨位和沉默会拖后第三拍；短战不如先手爆发，首两拍仍受甲克制。

### WR12｜点名决斗者
面板：H116 / A12 / T2.3秒 / R2 / 近 / 中甲。
能力：开战锁定自己的箭头所指敌人；在其存活时，该敌人对自身造成的每次直接普攻失血后，返还其3固定伤害，冷却1秒。返还不触发额外攻击；目标倒下后不重锁。
用法：针对与自己互指箭头的对位单挑；治疗和生命池比闪避式防护更容易维持返还。
弱点：对方让该敌人攻击队友便能绕开；完全吸收伤害或中途目标退场都会结束收益。

### WR13｜封创刀
面板：H92 / A10 / T1.9秒 / R0 / 近 / 轻甲。
能力：普攻命中给目标施加封创2秒：其收到的治疗减少40%，每次实际减少量转为等量创口储量；储量上限6，封创到期时一次造成等量物理伤害。重复施加只刷新期限，不提前结算；储量归同一施加者，不是流血层。
用法：集中火力对抗短周期治疗，把治疗损失变成延后伤害；适合与持续压血队友协作。
弱点：敌人没有治疗时只剩基础普攻；持续刷新会把储量推迟到战斗外，高甲也能压低兑现。

### WR14｜临终掷矛者
面板：H90 / A13 / T2.4秒 / R1 / 远 / 轻甲。
能力：最终退场时，向退场前当前目标结算12物理伤害，并令其攻击准备时间延长35%持续3秒；目标也在同批退场则此效果落空，不另选人。全战一次，无复起。
用法：使护送位的正常阵亡仍留下短暂减速窗口，帮助存活队友完成突破；无需主动自杀。
弱点：伤害受甲克制，且无法挽救己方全灭；被非主目标击倒或对方同时换代时作用有限。

## 贪婪｜GR01—GR14

构筑方向：存取与预支（01/02/03/08）、防护金融（04/05/06/07/12）、协作结算（09/10/11/13/14）。资源全为本场天赋记号，不涉及筹码。

### GR01｜藏币守卫
面板：H108 / A9 / T1.9秒 / R2 / 近 / 中甲。
能力：普攻命中存1币，上限4；失血后若生命比例低于50%且有币，清空全部币，每币补入4护盾，盾池上限16、持续4秒；取币冷却4秒。额外攻击也可存币，同一根事件只存一次。
用法：以持续接敌为自己攒应急盾，适配前半段保护和后半段承伤的分工。
弱点：未存钱就遭爆发会倒下；低频攻击、沉默和护盾清除让应急账户失效。

### GR02｜预支炮手
面板：H84 / A12 / T2.5秒 / R0 / 远 / 轻甲。
能力：开战后前两次普通普攻的伤害各提高10；第二次完成后，接下来的两次普通普攻准备各额外延长1秒。两个收益与两个偿还次数分别最多2，不因换目标重置。
用法：用明确的后续节奏债换开局突破，适配短窗口斩首或队友接力输出。
弱点：首两发被屏障化解后仍要偿还准备时间；长战和早期沉默显著降低回报。

### GR03｜封箱弩手
面板：H98 / A11 / T2.1秒 / R1 / 远 / 中甲。
能力：第一次普通普攻准备完成时不发射，改存一枚封箱；第二次普通普攻命中时消耗封箱，追加18物理伤害，并忽略目标本次追加伤害的至多4点R。每战仅封箱一次。
用法：将第一轮输出折进第二轮重击，适合等队友先破屏障、破甲再兑现。
弱点：被迫在第二次命中前退场就全无利息；分段盾、伤害上限和准备拖延针对其大额单次攻击。

### GR04｜借盾人
面板：H106 / A8 / T2.2秒 / R1 / 远 / 中甲。
能力：第2、8、14秒，给最低生命比例的其他队友12护盾、持续4秒；记录该盾实际吸收量，到期自身失去其中50%的生命，上限6。无队友则不放贷，债务不被沉默抹除。
用法：将关键队友的急性伤害变成自身稍后的可计划负担；搭配自愈或延时防护。
弱点：借款人没挨打则只是空转，自己残血时偿还可能致死；全队持续承压难以承受债期。

### GR05｜盾税官
面板：H92 / A10 / T2.0秒 / R1 / 远 / 轻甲。
能力：当前目标获得正数新护盾时，清除其此次实际新增长度的30%，单次最多4，并给自己等量护盾3秒；冷却2秒。同一根事件不再对由税收产生的盾征税。
用法：针对反复补盾而非一次大盾的敌人，将其续防节奏部分转为自身生存。
弱点：无盾和屏障队几乎不给税；对方在该角色被沉默时集中加盾能避开征收。

### GR06｜余疗出纳
面板：H94 / A8 / T2.0秒 / R0 / 远 / 轻甲。
能力：自己收到治疗时，记录被最大生命截去的过量部分；每满6点，扣6并给最低生命比例的其他队友5护盾3秒。余量上限12，每秒最多兑换一次。
用法：为已满血但仍有周期治疗的队伍提供余疗出口，能把自愈资源送到别的阵位。
弱点：自己持续受伤就没有过量；需要治疗投入，若同队缺承压目标会浪费第二次配置成本。

### GR07｜断盾修补师
面板：H112 / A7 / T2.4秒 / R3 / 近 / 重甲。
能力：其他队友的护盾被伤害消耗至0后，给其6护盾、持续2秒；全队共用4秒冷却。自己的修补盾再次破裂不触发本天赋。

能力：每名其他队友首次降至30%生命或以下且未致死时，自身自行失血8，给其14护盾3秒；若自己不高于8生命则不发动且不消耗该队友次数。每名队友每战最多一次，不恢复目标生命。

### LU11｜目送弓手

用法：让原本共享目标的双人队在失去一人后仍有短暂收尾火力，强调预先配对而非自动复仇。
弱点：若箭头不同或标记者同时退场，收益落空；本人提前被处理就没有残局窗口。

### LU12｜同行药袋

用法：给轻脆输出提供稳定攻击驱动医疗与流血缓解，适合让治疗者继续作战的双核阵容。

## 第一轮自审结论

- 计数目标：WR/GR/GL/EN/SL/LU/PR各01—14，共98；每名均有面板、能力、用法、弱点四行。
- 无第四实体、无交换阵位、无天赋整段复制；编号选择与箭头条件不等同于职业/装备硬禁令。所有队伍仍可自由装通用装备，但必须承担实际相性成本。
- 主要隐患一：护盾、转移、治疗可形成跨卡高续航。重复引擎已取消无必要的全战封顶，只以明确冷却、存量和单次额度控制吞吐；需专项跑24秒击杀率与有效伤害验证，不应再用隐藏的总次数预算截断提速或多段构筑。
- 主要隐患二：大量短窗口依赖0.1秒时间轴。执行器须统一同刻命中、净化、治疗、死亡的批处理，尤其是阈值治疗、复起、首击鉴定和最终击杀归属；不允许用玩家先后顺序裁定。
- 主要隐患三：EN的仿值与统计只在战斗内读取，不得成为试打窥探真实敌人的接口；箭头条件公开，但角色身份不直接揭晓。表现层必须让玩家看清实际事件而非泄露未触发能力。
- 主要隐患四：SL14已补自带预约作为启动器，不依赖特定装备才拥有实际技能；催期仍需逐笔记录归属与原定时间。仿值、反毒、吞屏障等反制型人物也须统计真实选用率，而非只看理论可触发。
- 主要隐患五：持续伤害来源、同名层刷新、按来源移除与多个来源护盾分池需按本页术语实现。若后续执行器只保留状态总层数或总盾量，封创、吞烬、借盾、合拍收束等不能可靠执行。
- 主要隐患六：本页已约定同批实际贡献正数伤害者视为共同击倒者；审阶的普攻击倒仍须有该批正数普攻贡献。需与装备/规则稿交叉核验同批奖励，不以客户端先到事件定输赢。
- 差异性复核：相近人物刻意分开支付方式、目标权限、时间窗或伤害通道，但仍可能存在环境性上下位。例如无状态环境让反制人物收益低，护送环境让特定防护过强；不把这种环境优势直接声明为已平衡。

## 本轮上限复核

- WR01怒量12、WR04减甲4层、WR13创口储量6均是当前存量，不是全战产出；维持。重复反击、吞盾、治疗、状态传播、三拍计数、预约与循环防护等删去额外的全战预算，不改基础面板、原冷却及单次效果量。
- PR05保留一次无瑕姿态及破瑕后不能恢复的风险，去掉五次命中封顶；GL12保留近战受击入口、1.5秒冷却和不由毒伤返伤续触发的约束。多段仍逐段独立根，派生事件仍沿根防循环。
- 保留的限次包括：GR02预支两发及两次偿还、GR03一枚封箱、GR08一次复起、GL06三份储粮、WR08/PR09每敌首个兑现机会、SL07/SL09一次保护、LU06两次封口、各自明确的开场或退场短窗口。它们是可提前兑现或围绕时机投资的有限资源，不是可重复基础引擎外加的战斗总闸门。
- 固定时点控场SL12、双节点援护SL13、EN14的两次阶段追赶仍保留其节点与弹药身份；GR09发薪、GR14结余、GL13震击、LU09合奏则按各自周期持续检查。新的主要测试对象是冷却内的多段收益、治疗有效量、护盾补入量和实际攻击窗口，而不是达到第N次后强制停机。
