# 镜头、位置、质感与资产规范

## 1. 不允许变味的部分

参考`reference/table-approved-A.png`。墨线、木刻排线、旧纸、磨损木头、暗金属；画面以黑褐、骨白、暗红为主。不是像素，不是写实PBR，不是现代赌场，不是暗黑网页后台。对手是坐在对面的人，随从是桌上活过来的小型人物，不是平铺的卡牌肖像。

颜色制作值：深底#171411、木色#33271E、墨黑#0B0B0A、纸色#C5B89A、主文字#E4D8BC、强调金#A98B51、愤怒红#9D3B32。其余罪色只作小面积识别，不给人物套整块彩色外发光。

质感要求：大轮廓先清楚，排线顺体积走；金属边缘用硬墨线和局部亮口，不能满屏镜面反光。灯光与烘焙手绘阴影不能互相矛盾。背景对比低于卡面与战斗人物，最亮处是可操作牌、必要提示和当前攻击落点。

## 2. 技术选型：制作定稿

Godot 4稳定版 + GDScript + Compatibility；桌椅/卡牌/筹码用简单3D网格，手绘贴图；随从、对手、荷官用2D分件骨骼和关键帧，在3D位置显示。先用本机已有稳定版并锁定准确版本及匹配导出模板，不能仅写“最新版”。

人物推荐固定尺寸SubViewport：Node2D分件/必要Skeleton2D/AnimationPlayer渲染为透明纹理，再由Sprite3D放在世界中。六名随从各一个512×512视口，更新时机按可见性管理；大人物另用1024×1024。若此方案在实测设备超预算，可换为同动作烘焙图集，不改造型与动作，不偷偷降成静态图。

主体竖直放置、固定朝向主镜头，足点对应桌面坐标；不跟随鼠标自由转面。阴影为独立手绘接触阴影片。分件内部层次在2D中解决；3D透明排序不得让跨位时头发穿过前方人物。桌面上的路径与投影使用单独平面/曲线，不把UI箭头焊死在屏幕。

网页导出以单线程Compatibility为基线，避免把依赖高级渲染或跨域隔离的方案作为必要条件。官方依据：[Web导出](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html)、[剪纸动画](https://docs.godotengine.org/en/stable/tutorials/animation/cutout_animation.html)、[Sprite3D](https://docs.godotengine.org/en/stable/classes/class_sprite3d.html)。这些资料说明可用技术，不证明本项目画面已经通过验收。

**编号约定**：本地固定视角两队从画左到画右均1/2/3，“对位”就是同一桌面列。底层保存canonical_lane=0/1/2和固定slot_id=1/2/3。将来另一方视角旋转180°时，两队在该视角从画左到画右均显示3/2/1，桌面印号一起旋转，不重新编号。指令传固定slot_id，“较小编号”不随观看方向改变，不能用两个互相冲突的编号系统。

## 4. 世界坐标与相机校准

制作起点：桌面XZ平面，Y向上；桌宽9单位、可见深度6单位。相机从(0,6,9)看向(0,0,0)，垂直FOV先46°；桌面近z=3.8、远z=-2.2。P足点x=-2.15/0/2.15,z=1.65；O足点x=-2.15/0/2.15,z=-1.35。

上面世界数值是校准起点，不与第3节同时硬锁导致错位。建`composition_calibration`调试场景：投影所有锚点，与第3节目标比较；仅允许一次集中调整相机位置/FOV、桌面比例、两排z间距，保存到唯一`table_layout.tres`。达到目标后，人物/荷官/卡槽不得各自写屏幕补丁追着镜头跑。验收截图必须显示校准误差表。

轻微视差：鼠标靠边仅让相机位置相对静态基点x±0.05/y±0.025世界单位，平滑时间0.25秒；不自由环绕，不改变焦距，不在攻击时自动拉近。触屏默认关闭视差。全屏抖动默认不使用，重击可桌面局部震动最多2屏幕像素/80ms。减少动态设置关闭视差和震动，但不跳过必要状态变化。

## 5. 图层和遮挡

从后到前：室内远墙 → 远侧对手/椅子 → 远桌边 → 桌面纹理和场地层 → 六人/台座/路径/投射物 → 近桌边 → 双手/手牌/筹码 → 交互文字层。

左右荷官有上身、前臂、手、牌四个独立遮挡组：上身在桌边后；手在发牌时可越过桌面；牌离手后交给CardView，不能两张重复出现。对手坐下时椅背应在身体后、桌沿应挡腰下。所有人物有足点接触阴影，不允许悬浮贴纸。

独立空间层不是一张大图上面补按钮。参考图只作构图/质感，禁止把整张图当背景然后在它自带六个角色上再放六个新角色。

## 7. 表现一致性与生成说明

先做角色正背面设定图，经比对通过后才生成分件与关键姿势。必须用同一角色参考，不许每帧重抽新长相。不得把缺失的背面用镜像正面替代。方向切换在身体转动的80—120ms过渡帧完成；不拿一块Sprite旋转180°露出纸边。

画面生成提示的固定部分：暗色木刻插画、粗细有变化的墨线、骨白纸底色、克制暗红/旧金、清晰剪影、人物部件完整可分离、固定参考角度、无文字无UI无背景角色。角色专属部分见04。不要在运行时调用图像模型；所有素材离线生成后导入。

装备在人物上仅显示一个通用附件锚点（腕/背/腰择一），保留角色原武器身份；明显改变普攻类型时换攻击表现，不把原来拳手直接换成另一个人物。效果槽显示足下独特小刻印和触发连线。战斗中只显示实际已存在的状态和资源。

## 8. 桌面不因场地换皮而消失

20个场地都发生在同一张牌桌中央：像桌上升起一块活过来的微缩地景。中央台面换地材、窄桥、短柱、薄水等，最高遮挡不超过角色身高的35%；台座位置不挪。房间/对手/双手/筹码不跟着改成另一套画风。

公共效果可覆霜、落雪、熄灯、裂盾或点亮刻痕；不做满屏雾盖住信息，不因“极寒”把全屏染蓝。场地变化必须有被改变的具体对象。详见05。
