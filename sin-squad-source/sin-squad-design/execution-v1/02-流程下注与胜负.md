# 流程、下注、胜负与信息权限

本文件是实施版本。金额是游戏内筹码，不是真钱。经济必须独立测试，不得用动画回调直接加减钱。

## 1. 三个时间尺度

- **房间/牌局**：一次携款入场，与一个对手连续下注、战斗；一方筹码归零或结算后离桌才结束。
- **一场/一手**：抽一个三人小队，公开规则与基础场地，准备/竞拍，战斗或弃牌结算奖池。下一手重新发队伍并清空装备、槽效和战斗状态，钱包保留。
- **准备轮**：一手内可有多轮下注。每轮至多一次付费配置操作，不等于多打一场战斗。

不要把“输了一个人物”当成永久丢掉角色。人物是这一手的牌，小队每手重发；98人全部开放，没有开包收集。

## 2. 房间与开始流程

制作参数：新档钱包1000；有上限场携入100/200/500；无上限场携入整个当前钱包。各档底注均先用5。最低可带10；不足10回到大厅并提供明确标注的“重置离线测试存档”，不悄悄发钱。

有上限指**携入金额上限**，不是单次下注上限。每次下注最多自己当前可用桌上筹码，无额外硬封顶；不开放负债。电脑携入与玩家相同金额，测试中外部对手资金单独记来源，不能当成玩家的钱。结算后可离桌，不允许在一手中从钱包补钱。

```text
标题 → 桌面大厅 → 选档 → 预加载必要素材
 → 固定4.8秒对手入场/荷官就位/筹码发放（同时初始化本手）
 → 双方底注 → 规则和基础场地翻明 → 发三人小队
 → 准备轮0
 → 公共效果1争夺 → 准备轮1
 → 公共效果2争夺 → 准备轮2
 → 公共效果3争夺 → 准备轮3及以后
 → 自动战斗或弃牌 → 结算
 → 下一手（对手不重新入场） / 离桌
```

对手入场只在本次入桌时一次。下一手只收旧牌、发新牌；不要每战叫同一个对手离开再进来。

队伍：正式版从全部98个人物为每方分别抽3个不同ID，双方可抽到同一人物；不得按强弱故意给电脑好队。不把测试剧情脚本混进自由对局，不用少数样板代替完整内容池。三张公共效果本手内不重样。

底注不足5时双方按较少者剩余筹码与5的较小值交相同底注；出现全下即按全下规则早开战。不能凭剩4筹码免费弃牌无限拖局。

## 3. 准备轮下注

变量：`round_paid[player]`本准备轮已交的普通下注；`target_bid`当前需要匹配的总额；`operation_fee`另账，不参与差额比较。进入新准备轮普通下注账归零，之前的钱仍在奖池。

合法动作：

| 动作 | 合法条件 | 钱与后续 |
|---|---|---|
| 过牌 | 当前无人下注，自己无差额 | 不花钱；双方均过牌才结束本准备轮 |
| 下注 | target_bid=0 | 报本轮总额，最少5；不足5只允许全下 |
| 跟注 | 自己有差额 | 只付target_bid-round_paid，不重复交过去各轮的钱 |
| 加注 | 当前有报价 | 报更高本轮总额，增量至少5；不足时只允许合法全下补差 |
| 弃牌 | 自己的合法决策窗口 | 输掉本手全部已投入；不揭自己的小队 |
| 全下 | 本轮动作允许出价/跟注 | 付桌上所有可用钱；不能透支或自动追加钱包 |

第一个准备轮先行动方随机；同一手之后准备轮首行动方交替；下一手反转最初首行动方。电脑不能知道玩家尚未提交的选择。

双方匹配同一普通下注总额B以后，进入一次**同时决定操作**的阶段：

- 不操作：无追加，普通下注已花B。
- 操作：再付B，合计本轮2B，可做下列一种配置操作。
- B=0双方过牌：本轮无配置操作，直接推进公开效果或开战。想拿牌至少先下5，不能0元刷牌。
- 操作决定、安装位置、箭头修改均先私下提交，双方齐备才一同公开；钱不足B的人只能不操作，显示原因。
- 非操作是“相同匹配下注下少付一份操作费”，不是永远能用对方下注的一半留在任何赌局中。

例：甲报10，乙报30，甲再付20跟到30。甲买配置操作再付30、乙不买；这一轮甲入池60，乙30。后面一轮从0重新计下注。若甲弃牌，60及以前投入都归乙；若甲胜，赢当前整个奖池。

无牌操作也能主动叫高价诈唬。**叫价本身不能免费做配置操作；每次加价不增加一次拿牌权。**

## 4. 三种配置操作

选择前显示准确总费用，扣费后流程不可通过返回菜单免费撤销：

1. **拿一张牌**：先付费，再出现混池三选一；装备与槽效混在一起。必须选1张并安装在己方合法的对应槽。已有牌被替换即丢弃；不能存手里以后免费上。三个候选可以同类型，按ID本次不重样。不提供免费刷新。
2. **调配牌槽**：移动一张装备到己方另一装备槽，或一张槽效到另一效果槽；目的地非空则两张交换。类型不能交叉。一次仅一组移动/交换。
3. **调整指令**：本次可更改己方三条主攻箭头，整体确认算一次；允许只改一条。不能移动人物编号，不能修改敌方箭头。

牌槽操作公开结果，不公开自己的基础面板。候选牌对本人私有，已选安装牌公开。打开自己的详情、查看已公开牌和稻草人试打不花钱，但正式联机中不停止对方计时（后续再加计时，首版不加）。

任何配置更新后还有下一次准备轮回应机会。第三张公共效果以后，只有一次新准备轮内双方均过牌，才开战；不能自己换完箭头立即按按钮不让对方回应。

## 5. 公共效果争夺

公共效果按1、2、3依次翻开。双方先私下提交“生效/不生效”，再一起公开。

- 都生效：免费加入本场。
- 都不生效：免费弃置。
- 不同意：希望生效的一方先报价，至少5；另一方可报更高价格买“不生效”；交替竞价。
- 报价是购买本张公共效果最终状态的总价，不是每次加价都交一遍。仅胜者在结束时交最后报价入池，败方报价不扣。
- 可以放弃本次竞价；这不等于弃掉整手。也可以另外按“弃掉本手”结束本场，两按钮必须不同文字。
- 希望生效的一方若不愿首次付费，按其放弃竞价处理，本张不生效且无人付费。
- 争夺中报价不得超过自己的可用筹码；不能调用主下注跟注逻辑扣另一人钱。
- 赢家付费后可用钱恰好为0，锁定已生效环境并早开战，不继续翻未揭示牌。

对局里没有“任何瞬间鼠标乱点都能抢出价”。任意阶段可叫价指每个合法准备/争夺窗口，不允许在对方牌还飞行时插队破坏状态机。

## 6. 全下和离桌

这是本游戏自己的规则，不套用未说明的德州边池：

1. 普通下注一方无法全额匹配时，可全下。双方本轮普通下注取可匹配的较小总额；退回另一人**本轮普通下注超额**。旧轮下注、已付操作费、已付公共竞价不退。
2. 普通下注匹配后只要一方剩0，不开启新的操作阶段，直接揭队开战。
3. 若双方已进入操作阶段，一方因支付操作费剩0：双方这一批已提交且可支付的操作都完成并一起公开，再开战；不能取消对方已提交操作。
4. 尚未翻开的公共效果不生效。已经生效的保留。
5. “筹码暂时0”不等于已经输掉牌局：该人仍可能赢回奖池。
6. 弃牌会立即结算本手；普通关闭窗口/刷新不伪装成免费退出。离线恢复到最近已提交状态，避免读取一组候选后读档换一组。
7. 仅在本手已结算时允许“离桌”：桌上剩钱转回钱包一次。不能重复点领两份。

## 7. 全部30条胜利规则

正式版启用父目录VC01—VC30，逐项实现，见09执行表。教程先用VC01，再实际演示一条提前获胜规则；这不限制自由对局内容。不要另外生成一组只有三条的RV规则。

规则提前可见，具体关键人位置在正式揭队时公开；准备时不公开旗手在哪。默认24秒，VC21为12秒，VC22为36秒；不能所有规则硬写24秒。

每条都保留全灭作为备用取胜路，但不额外写“全灭优先盖过已经同时达成的目标”。一个tick内完成全部既有同刻结算、退场/复起及有限派生后，分别计算双方win_claim（规则达成或敌全灭）。只有一方有claim则赢；两方都有则平局；两队同时全灭也平局。已判胜时不结算未来tick。允许玩家通过不同路线同刻撞线，不用代码先处理谁就让谁赢。

健康度=当前生命/开战最大生命，最高1，最终退场按0。血条不显示伤害为0时的假扣血。在期限T内只调度0≤t<T的战斗事件，t=T执行限时比较，不额外赠送一次攻击或周期跳伤。持续计时满足时刻若恰好为T，先按09的计时约定处理，再做限时比较。

## 8. 信息权限

| 项目 | 本人 | 对手准备时 | 开战后 |
|---|---|---|---|
| 自己三人ID、面板、天赋 | 可见 | 不可见 | 全部可见 |
| 装备、槽效、主攻箭头 | 可见 | 可见 | 可见 |
| 未选候选牌 | 可见 | 不可见 | 不公开 |
| 筹码、累计奖池、公开下注 | 可见 | 可见 | 可见 |
| yes/no或本轮操作未提交信息 | 仅自己 | 不可见 | 提交齐后公开结果 |
| 未翻公共效果 | 不可见 | 不可见 | 只有实际翻过的可见 |
| 隐藏人物衍生量（总HP、旗手、某装备预期伤害） | 自己可见 | 不可见 | 可见 |

敌人表情、封牌高度、脚印、阴影、声音、加载时长、头像占位、AI评估日志都不能泄露未公开身份。稻草人模拟只拿本人配置+公开环境，不能拿真实敌队“匿名化后”再测。

## 9. 经济不变量

玩家钱包+玩家桌上+对手钱包/资金账+对手桌上+奖池 = 本牌局初始总额；退款、离桌和结算只是搬运。每笔带唯一transaction_id，重放不重复付费。UI显示每个动作前后变化；结算列“本手投入/奖池收入/本手净赢亏”，不要把拿回自己的下注全写成利润。

完全平局按每方本手实际投入原样退回，不平分奖池。2B与B不等额局平分会变成隐形转钱，必须测试。
